# NP-002 文字糊/假字 (fake_text)

## 规则
生成模型渲染画面内文字是高失败率操作 (假字/乱码/糊字), 且混在纹理里后期难修。规则:
1. 提示词层: 负面/约束段固定携带"无字幕/无水印/无logo/画面中不出现文字";
2. 首帧层: 首帧描述尾部强制追加"无运动, 无文字, 无水印" (静态可拍、无叠加文字的画面定义);
3. 需求层: 剧情确需文字信息 (招牌/字幕/界面) 时, 走后期叠加路线, 生成画面只留承载文字的干净区域;
4. 验收层: 画面内出现假字/糊字 → 按 `fake_text` 类目登记问题单返修, 不得冒充"可接受噪点"。

## 判例
来源为仓库内置生产问题单模板: categories 第三项 `"fake_text",  # 假字/招牌` (与 face_drift/hand_extra_finger 等并列), 说明"定剪后独立清理 pass: 手脸/文字/接缝/颜色/环境声/待补镜头"——文字类缺陷是生产流程里的正式清理对象, 不是可忽略细节。代码层防线同步存在: aigc_prompt_builder 的负面约束基线 `base = ["无字幕", "无水印", "无logo", "画面中不出现文字", "角色外观与服装跨镜头一致"]`; scene_entity.first_frame_desc 每条首帧尾缀 `。无运动, 无文字, 无水印。`。
诚实边界: 本仓库无本地实测的"文字糊"返工判例 (不产像素); 本条为预防性规则, 证据指向仓库内已落地的三处防线。

## 自检
- 提示词是否携带完整文字排除约束 (无字幕/无水印/无logo/画面中不出现文字)?
- 首帧描述是否以"无运动, 无文字, 无水印"收尾?
- 成片中所有文字是否均为后期叠加? 假字/糊字是否进 fake_text 问题单?
