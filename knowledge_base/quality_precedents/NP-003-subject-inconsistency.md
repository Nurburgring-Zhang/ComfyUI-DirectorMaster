# NP-003 主体不一致 (角色漂移/单字误判)

## 规则
主体不一致是跨链路返工的头号来源: 分镜里叫 A、AIGC 角色锚写 B、POV 又写 C, 下游每个消费点都要返工。规则:
1. 单一事实源: 主体名以用户场景实体解析结果为最高优先, 核心包角色锚补位, 罐头角色只在无实体时诚实回退;
2. 单字误判防线: char_map 单字映射 ("女"→"女儿"式) 在候选被用户实体包含时必须丢弃——实体优先, 词典让位;
3. 全链一致: 分镜画面 focus / 剧本角色 / AIGC 角色锚 / POV / 音频描述五处的主体名逐字相同;
4. 审查口径: 五链抽查主体名, 出现第二种叫法即判主体不一致, 返工重写而非局部替换。

## 判例
V16.5 场景实体引擎的立项证据就是一次主体不一致返工: 全维度矩阵首轮实测中, 用户场景"女机甲战士在暴雨码头开启能量护盾"的分镜被罐头内容污染——"女儿/护士"顶替了用户的"女机甲战士"。修复方案是 `aggregator/scene_engine.parse_scene` 融合实体引擎: char_map 单字误判角色"女→女儿"在被实体包含时丢弃 (实体优先); 同一提交把分镜画面/剧本角色/AIGC 角色锚/POV/音频全链改为用户实体化, 实测"机甲"143 次命中、"女儿"139→0。Cinematic 的接线点保留至今: `# V16.5: 用户实体优先 — 场景实体引擎提取的角色/道具覆盖罐头解析 (修复 POV/角色锚/AIGC提示词 仍写"女儿/护士"等罐头角色的问题)`。

## 自检
- 抽 3 镜 + 剧本 + AIGC 锚 + 音频: 主体名是否逐字一致?
- 是否存在用户场景中不存在的角色名 (罐头角色)?
- 单字 char_map 命中的角色词, 是否被用户实体包含性检查复核过?
