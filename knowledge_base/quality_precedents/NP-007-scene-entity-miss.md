# NP-007 场景脱节 (罐头内容, scene-entity miss)

## 规则
"分镜写得再工整, 与用户场景无关就是废稿"。规则:
1. 硬门口径: 用户场景实体 (主角色/主道具) 必须以可计数的频率出现在分镜画面中——主角色命中 ≥min(3, 镜数//2+1) 镜, 主道具 ≥min(2, 镜数//4+1) 镜; 一镜到底 (是枝式 1 镜) 也须命中 ≥1;
2. 罐头池定位: 罐头内容池只允许在用户场景提取不到实体 (has_entities=False) 时作诚实回退, 且输出不得暗示那是用户实体;
3. 全链命中: 分镜画面 focus / 剧本 / AIGC 锚 / POV / 音频 同一实体口径 (与 NP-003 联动);
4. 验收: 实体命中不达标 = hard_fail, 整例返工, 不进入质量项平均。

## 判例
V16.5 CHANGELOG 背景节记录了完整判例: "构建全维度测试矩阵 (71 用例) 实测剧本+分镜输出。首轮实测暴露内容级鸿沟: 用户场景'女机甲战士在暴雨码头开启能量护盾'产出'辣椒酱/女儿/护士'罐头内容 (用户实体命中≈0)。本版以场景实体引擎彻底修复。" 修复节给出量化结果: "实测: 机甲场景'机甲'143 次命中、'女儿'139→0; 父女厨房经典场景罐头池正常服务不受影响"——注意修复没有删除罐头池, 而是给它划定了诚实回退边界。矩阵测试把该口径固化为硬门: `hard.append((f"场景实体命中(主角色{c0})", hit >= max(1, min(3, _n // 2 + 1))))`。

## 自检
- 统计主角色/主道具在分镜画面字段的命中镜数: 是否达到硬门下限?
- 分镜正文能否让没读过用户输入的人复述出原场景?
- 罐头内容是否只出现在无实体回退分支, 且未冒充用户实体?
