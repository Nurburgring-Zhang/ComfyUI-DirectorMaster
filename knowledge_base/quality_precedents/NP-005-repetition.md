# NP-005 复读后缀 / 正文雷同 (repetition & near-duplicate)

## 规则
复读有两种形态, 都按红线处理:
1. 镜间复读: 相邻镜头画面焦点逐字相同 (模板句连发), 重复率硬上限 15%;
2. 模式间雷同: 同档期两个形态模式对同一输入产出高相似正文——用户换模式却拿到同一段话, 是功能性虚假。
红线数值: 相邻焦点重复率≤15%; 形态对 bigram 相似度<0.7 (审计基线 0.91 即失败案例); 同节奏簇模式间景别/运镜/焦段/时长四元组指纹必须两两唯一。

## 判例
D2 探针文件头记录了判例原型: "验收: 全部形态对相似度 <0.7 (审计基线: 创意玩法 vs 爆火反转 = 0.91)"——即审计曾实测到两个短视频形态模式对同一场景输出 0.91 相似度的近复制文, 随后建 16 个同档期形态对的常驻探针, 任何一对 ≥0.7 即非零退出。镜间复读红线由 V16.4 test_random_full_v16 落地: `dup = sum(... 相邻焦点逐字相同 ...); check(相邻焦点重复率≤15%, dup/(len-1) <= 0.15)`。语法指纹唯一性由 D1 守门: 同一核心包跑全部 Cinematic 模式, 全字段指纹与镜头语法子集指纹双重唯一, 同簇碰撞列出模式名并 exit 1 (d1_grammar_probe.py:123-127)。

## 自检
- 抽任意相邻两镜: 焦点行是否逐字不同? 全片相邻重复率是否 ≤15%?
- 同档期模式抽查: 两模式输出是否 <0.7?
- 同节奏簇内模式: 景别/运镜/焦段/时长语法指纹是否唯一?
