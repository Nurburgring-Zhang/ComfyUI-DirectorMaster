## 意图

一场戏想"以不说来演"时选它：输出沉默场景的类型定位与四项占比口径，把留白变成可执行的声音调度。与"声音设计"Layer4 的本质差别：整场以沉默为主角，沉默不是收尾手段而是结构本体。

## 核心手法

1. 场景类型声明"对话极少, 沉默是主角"；沉默总时长按场戏节奏，关键情感点前必留。
2. 每句对白前固定停顿 0.5s——呼吸、眼睛看别处、然后开口。
3. 四项占比口径：对白间沉默 0.4（用首个道具的动作声填充）、动作后停顿 0.3、眼神对视 0.3（{c1}看{c2}, {c2}看别处）、空镜留白 0.2（道具与空间）。
4. 结尾绑定导演风格："留白即叙事, 沉默即对白"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _场景描述/_情绪基调 的 Core JSON | 空包时角色回退"主角"、填充道具回退"关键道具" |
| 留白比例 | 0.3（FLOAT 0-1 步长0.1） | 仅维度块"沉默层占总时长30%"——不改正文的 0.5s 停顿与四项占比数字 |
| 声音密度 | 无(默认)→适中 | 维度块列值；极静/针落有声等值不会改写占比 |
| 启用反AI规则 | True | False 时跳过套话清洗 |

## 已知坑

四项占比 0.4+0.3+0.3+0.2=1.2，是各口径独立给出、非闭合归一的比例，不能直接当时间轴百分比使用；单角色场景对视行写成"{主角}看{主角}"（chars[1] 回退 chars[0]）；0.5s 停顿为写死值，无参数可调。
