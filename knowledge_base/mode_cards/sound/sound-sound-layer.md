## 意图

现场收音/拟音要一份逐层清单时选它：按说话角色/沉默角色/空气层/脚步层/环境动作层/远景层拆解，每层一句话口径。与"声音设计"的本质差别：纯物理分层清单（无心声/沉默层），面向执行不面向混音意境。

## 核心手法

1. 说话角色=首个角色（"声音频率/语速按角色前史定, 停顿多"）；沉默角色=第二个角色（"非语言: 呼吸/眨眼/动作声"）——单角色场景两者同名。
2. 空气层=天气声（持续, 中景, 包裹感），天气缺省"环境"。
3. 脚步层按地点地面材质定；环境动作层列前 3 个物件的材质声。
4. 远景层=地点的远处声（偶尔, 低频）；画幅行声明"按核心数据包"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _场景描述/_情绪基调 的 Core JSON | 空包时角色回退"主角"、地点回退"场景"、天气回退"环境" |
| 声音密度 | 无(默认)→适中 | 维度块"声音元素数量按此控制"，六层清单条目数不增减 |
| 声音风格 | 无(默认)→写实 | 维度块经 SOUND_STYLE_MAP 落写实口径；本模式正文不按风格分层 |
| 混响空间 | 无(默认)→中混响 | 维度块注入距离感描述；正文层定义不变 |

## 已知坑

场景只有 1 个角色时"说话角色"与"沉默角色"是同一个名字（chars[1] 回退 chars[0]），出现"主角既说话又沉默"的矛盾行；天气解析不到时空气层写作"环境声(持续…)"同义反复；各层无响度/电平数值。
