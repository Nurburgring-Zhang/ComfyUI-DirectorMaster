## 意图

定"这场戏用什么乐"的方向时选它：按情绪映射配乐风格并给情感曲线/时代适配/留白点。与"声音设计"的本质差别：只管音乐层，不管环境/拟音/心声。

## 核心手法

1. 情绪→风格八档映射：孤独→极简钢琴+弦乐拨弦无鼓机；温暖→原声吉他+轻弦乐；悲伤→大提琴独奏+钢琴单音；悬疑→低音弦乐+不规则打击；史诗→管弦乐+民族打击；宁静→氛围长音；喜剧→轻快拨弦+木管；浪漫→弦乐+钢琴；八档外→"极简配乐, 克制"。
2. 情感曲线固定"递进——从单音到双音, 高潮后回到单音"；BPM 按情绪与场景动作节奏同步（无具体数值）。
3. 时代适配：古装→"可加民族乐器(古琴/笛/鼓)点缀"、科幻→"合成器低频铺底"，其余年代无备注。
4. 留白点两规则：道具出现时静音 0.5-1s；关键情感点前抽配乐。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 音乐风格 | 无(默认)→极简钢琴 | 维度块经 MUSIC_MAP 落"极简钢琴(单音/双音, 坂本龙一式)"；正文风格只按情绪映射 |
| 音乐风格_多选 | 空（如"极简钢琴→古典交响→氛围音乐"） | 单值时首值覆盖单选；>1 值追加【配乐演变弧】块（建置/上升/高潮/解决 + motif 贯穿过渡建议），值原样列出无映射 |
| 核心数据包 | 含 _场景描述 的 Core JSON | 空包时道具回退"关键道具"、情绪回退"孤独" |
| 启用反AI规则 | True | False 时跳过套话清洗 |

## 已知坑

核心包缺省情绪"孤独"未改时全按极简钢琴路数写；八档外的情绪（恐惧/怀旧等）全部落缺省句"极简配乐, 克制"；年代备注只覆盖古装/科幻，其余输出"时代适配: 现代——"带悬空破折号；配乐演变弧的值不做风格描述映射，只原样列出。
