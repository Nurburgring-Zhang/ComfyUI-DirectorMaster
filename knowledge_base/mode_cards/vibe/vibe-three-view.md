## 意图

给角色/产品定"怎么造"的制图基准时选它：规定正视图/侧视图/俯视图三视角同比例尺对齐的设计要求。与"爆炸拆解图设计"的本质差别：表达外观三个正交视角，不拆内部装配关系。

## 核心手法

1. modes_design._build_three_view_prompt：三视图=正(前)/侧(左或右)/俯(上)，三视角一致比例。
2. 主体对齐用基准线；线条为工业制图风格：粗轮廓+细结构线，尺寸标注可选。
3. 细节规则"同一部件三视角一致"；可附材质/工艺说明。
4. 适配器传 style=扁平矢量、产品槽=场景解析首个人物或物件（空则"产品待定"）、材质/颜色槽恒空→显示"待定"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _视觉调性/_场景描述 的 JSON | 空包时色彩基调落"高对比"、产品行落"产品待定" |
| 产品材质/产品颜色 | 实现签名存在但适配器恒传 "" | 提示词显示"待定"，材质工艺标注落空 |
| 数量 count | 4（适配器硬编码） | 非用户参数 |
| 启用反AI规则 | True | False 时输出保留套话 |

## 已知坑

尺寸标注标注为"可选"且无尺寸数值来源——节点不产出任何具体尺寸，制图精度靠下游；产品只取场景解析的第一个名词，多部件产品需在场景文本中写明部件清单。
