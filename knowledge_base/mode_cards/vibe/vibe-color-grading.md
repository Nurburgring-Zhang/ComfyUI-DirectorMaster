## 意图

定全片色彩基调与逐场色变规则时选它：输出调色基调/60-30-10 配色/暗部高光规则/肤色锚定/情绪曲线五行。与"世界设定"的本质差别：只管画面颜色处理，不管空间与声音锚点。

## 核心手法

1. 基调行由情绪+年代共同决定（"调色基调: {mood}, 时代={era}"）。
2. 60-30-10：主色按 _视觉调性（缺省"写实"）定、辅色按情绪定、点缀色=首个道具的颜色——与美术/世界设定共用同一套配色口径。
3. 暗部"保留细节不死黑"、高光"不过曝留呼吸"两条硬规则。
4. 肤色以首个角色为锚要求全片一致；情绪曲线行规定"低谷偏冷, 高潮对比增强"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _视觉调性/_场景描述 的 JSON | 空包时主色依据回退"写实"、点缀色回退"关键道具的颜色" |
| 情感浓度 | 无(默认)→适中(平衡) | 仅注入【维度配置】块；正文色调只看情绪基调配档 |
| 启用反AI规则 | True | False 时跳过套话清洗 |
| 色彩基调来源 | 核心包 _情绪基调（缺省 孤独） | 缺省即"孤独"→ 全篇按冷调写情绪曲线，需显式覆盖 |

## 已知坑

输出是定性调色方向，无任何具体数值（无 LUT/色温 K 数/示波器口径），数值化要靠 AI 轨或下游 color_grading_pro 等模块；情绪基调来自核心包缺省"孤独"而不接节点下拉，忘改核心包时全片被写成冷调。
