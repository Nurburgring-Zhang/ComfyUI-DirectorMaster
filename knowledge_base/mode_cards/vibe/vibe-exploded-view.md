## 意图

展示一个产品"由哪些件怎么装起来"时选它：规定装配轴展开、部件分层、引导虚线、等轴测视角的设计要求。与"三视图设计"的本质差别：拆内部结构关系，不画外观正交视角。

## 核心手法

1. modes_design._build_exploded_view_prompt：沿装配轴爆炸展开，部件按装配顺序分层，层间距均匀。
2. 引导虚线连接部件与装配位，方向=装配方向；部件编号对应。
3. 视角规定等轴测/45 度俯视最佳，展现立体装配关系；各部件材质/工艺标注、颜色区分。
4. 适配器传 style=扁平矢量、产品槽=场景解析首个人物或物件（空则"产品待定"）、材质槽恒空→"待定"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _视觉调性/_场景描述 的 JSON | 空包时色彩基调落"高对比"、产品行落"产品待定" |
| 产品材质 | 适配器恒传 "" | 材质标注行显示"待定" |
| 数量 count | 4（适配器硬编码） | 非用户参数 |
| 启用反AI规则 | True | False 时输出保留套话 |

## 已知坑

部件清单与装配顺序无结构化输入——全靠场景文本描述，未描述的部件不会出现；视角给的是"等轴测/45 度俯视"二选口径，无用户参数可锁定其一。
