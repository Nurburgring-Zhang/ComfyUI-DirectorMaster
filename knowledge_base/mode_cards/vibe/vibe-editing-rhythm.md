## 意图

给剪辑师定"这场戏怎么切"的规则时选它：输出节奏总则/本场切点/转场逻辑/留白/禁忌五行。与"MV导演"的本质差别：以情绪与动作为切点依据，不以音乐节拍为轴。

## 核心手法

1. 节奏总则按情绪定性："低谷长镜, 高潮短切"。
2. 本场切点三选一规则：首个角色的 动作/视线/呼吸，三选一切。
3. 转场逻辑行固定"镜B回答镜A的'然后呢', 不为了切而切"。
4. 留白规则"关键情感点后留 1-2 秒静帧"；禁忌行禁无意义快切。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _场景描述 的 JSON 供 parse_scene 取角色 | 空包时切点主体回退"主角"，指称悬空 |
| 情绪浓度 | 无(默认)→适中(平衡) | 仅注入【维度配置】块，长镜/短切只按情绪基调定性 |
| 启用反AI规则 | True | False 时输出保留套话 |

## 已知坑

全部规则是定性描述，无镜头时长数值（没有"低谷≥X 秒"类参数），秒级剪辑表需下游补；切点只围绕首个角色展开，多人群戏的切点未覆盖。
