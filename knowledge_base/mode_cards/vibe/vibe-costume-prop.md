## 意图

需要给每个登场角色一套可执行的衣服+道具清单时选它：输出时代/逐角色服装/材质重点/色彩方案/关键道具/道具叙事功能六段。与"世界设定"的本质差别：只管人物穿戴与手持物，不定义空间与社会规则。

## 核心手法

1. parse_scene 取前 3 个角色逐人生成一行"{角色}: {年代服装基调}, 细节随角色前史磨损"。
2. 年代服装基调查内置四档表：古装→宽袖长袍/布料粗粝/按身份等级配色、科幻→无缝功能面料/哑光/有使用磨损、复古→洗旧整洁/低饱和/年代剪裁痕迹、现代→当代成衣/生活褶皱。
3. 色彩方案：低饱和 + 按情绪定冷暖 + 点缀色来自首个道具。
4. 道具行用 _关键道具（空则 parse_scene 道具顿号拼接），并给每件道具绑定叙事功能"承载一段未说出的'{主题}'"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _时间年代/_关键道具/_主题词 的 JSON | 空包时年代回退"现代"、道具回退 parse_scene 结果、主题回退"情感" |
| 情感浓度 | 无(默认)→适中(平衡) | 仅注入【维度配置】块，服装基调不随浓度变化 |
| 商业卖点 | 无(默认)→有卖点(艺术+商业) | 仅进维度块，正文无消费 |
| 启用反AI规则 | True | False 时输出保留 AI 套话 |

## 已知坑

前 3 个角色共用同一句年代基调，只在行首换角色名——没有角色间身份/阶级的服装差异化设计，需要人工在"按身份等级"提示基础上二次拆分；角色超过 3 个时第 4 人起完全不出现。
