## 意图

把一场戏改造成"观众替角色做选择"的互动结构时选它：输出互动节点/分支A/分支B/汇合点/选择设计五行。与"漫剧分镜"的本质差别：组织的是选择与代价，不是画面格。

## 核心手法

1. 互动节点定位在首个道具前："{角色}在{道具}前面临选择"。
2. 分支A固定"拿起{道具}→真相线"，分支B固定"转身离开→遗憾线"。
3. 汇合点行强制两条线在结尾回到'{主题}'，保证分支不散架。
4. 选择设计行给原则"无绝对对错, 只有不同代价"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _主题词/_场景描述 的 JSON | 空包时抉择点回退"主角在关键道具前"，主题回退"情感" |
| 创意方向 | 无(默认)→商业类型片 | 仅注入【维度配置】块，分支结构固定不变 |
| 启用反AI规则 | True | False 时跳过套话清洗 |

## 已知坑

分支结构恒为二分支且线名固定（真相线/遗憾线）——三分支、多级嵌套互动需人工重构；单次输出只含 1 个互动节点，多抉择点剧本要逐场多次运行。
