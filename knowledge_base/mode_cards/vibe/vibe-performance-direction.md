## 意图

导演要给演员一条可照做的本场表演提示时选它：输出角色/本场目标/内在动作/视线设计/呼吸节奏/禁忌/导演提示七行。与"互动剧"的本质差别：这里指挥单场内的身体行为，不构建分支剧情。

## 核心手法

1. 取前两个角色与首个道具填空：角色行声明"由演员承载'{主题}'"。
2. 内在动作固定骨架"手停在{道具}上, 0.5秒, 又若无其事地继续"；视线设计固定"看{对手}→移开→再看, 三次, 每次更短"。
3. 呼吸节奏行给"说话前吸气—说到一半屏住—说完才呼出"三段式。
4. 禁忌行固定"不许用脸'演'情绪"；导演提示取 _导演意图_观众应感到，空则回退"让观众自己发现, 不告诉观众"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _主题词/_导演意图_观众应感到 的 JSON | 空包时主题回退"情感"、导演提示回退固定句 |
| 创意方向 | 无(默认)→商业类型片 | 仅注入【维度配置】块，表演骨架不随方向变化 |
| 启用反AI规则 | True | False 时跳过 anti_ai_vocab 清洗 |
| 核心数据包(场景) | _场景描述 供 parse_scene 取角色/道具 | 空包时角色恒"主角"、道具恒"关键道具"，指令失去指称对象 |

## 已知坑

动作/视线/呼吸三段是固定句式，只随角色名与道具名变化——两场完全不同的戏会得到仅换了名词的同一套指令；场景只有 1 个角色时，视线设计的对手{c2}回退为同一角色名，出现"看自己"的病句。
