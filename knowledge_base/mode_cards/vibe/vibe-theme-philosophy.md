## 意图

输入已有主题雏形、想把"故事讲什么"升维成"故事关于什么"时选它：输出主题句/道德困境/哲学内核/隐喻/潜文本/结尾留白六段。与"概念立项"的本质差别：这里没有任何商业表述，交付的是判断权留给观众的思想框架。

## 核心手法

1. parse_scene 取首个道具作为全篇隐喻载体；核心数据包取 _主题词（缺省"记忆"）与 _核心冲突（缺省"家庭"）。
2. 道德困境行套两难句式："{冲突}的两难——说出来会破坏, 不说会积压"，哲学内核以"是保护, 还是会变成一种伤害?"问句收口。
3. 隐喻行固定映射"{道具} = 未完成的'{主题}', 一直在场, 一直未被正视"。
4. 潜文本取 _潜文本_情感；结尾留白行固定"不给答案, 把'{主题}'的判断权交还给观众"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _主题词/_核心冲突/_潜文本_情感 的 JSON | 空包时全用缺省：主题"记忆"/冲突"家庭"/潜文本"真正想说的, 一直没说出来" |
| 导演风格 | 继承核心包 _导演风格（缺省 王家卫） | 库内无此导演时 get_director_profile 返回空，输出无【导演风格锚定】块 |
| 启用反AI规则 | True | False 时输出不做套话清洗 |
| 情感浓度 | 无(默认)→适中(平衡) | 只注入【维度配置】块；本模式正文无情绪分支消费 |

## 已知坑

潜文本字段 _潜文本_情感 缺失时回退固定句"真正想说的, 一直没说出来"——不同项目会输出同一句；隐喻恒取 parse_scene 的 objects[0]，多道具场景其余道具全部忽略，隐喻选错道具时需回改场景描述顺序。
