## 意图

成稿后想知道"主题到底传没传到"时选它：输出迭代焦点/检查项1-3/改进方向五行，把问题收敛到动机、道具、节奏三个可判定的点。与"质量QA"的本质差别：查叙事是否达意，不查穿帮与一致性。

## 核心手法

1. 迭代焦点绑定主题："本场'{主题}'是否被观众接收到"。
2. 检查项1：首个角色的动机能否被观众一句话说出。
3. 检查项2：首个道具是否承担情感——"去掉它故事是否塌"。
4. 检查项3：节奏两问（低谷太长/高潮太赶）；改进方向固定"强化潜文本, 削弱直白台词"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _主题词/_场景描述 的 JSON | 空包时主题回退"情感"、角色/道具回退占位词，检查项失去对象 |
| 创意方向 | 无(默认)→商业类型片 | 仅注入【维度配置】块 |
| 启用反AI规则 | True | False 时跳过套话清洗 |

## 已知坑

本模式是单轮自查清单生成器——节点没有"上一稿输入"参数，不消费历史输出，也不会自动改稿；"迭代"指检查视角而非自动多轮循环，多轮迭代需人工带着清单回改后再跑。
