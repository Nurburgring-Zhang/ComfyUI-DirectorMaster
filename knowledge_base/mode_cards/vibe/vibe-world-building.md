## 意图

开拍/生成前需要"这个世界长什么样"的统一口径时选它：输出时间/空间/时代质感/社会规则/登场人物/视觉锚点/声音锚点/主色配比八段。与"服化道"的本质差别：这里定义世界运行规则与感官锚点，服化道只管人物身上穿什么带什么。

## 核心手法

1. parse_scene 取 地点/时间/天气/人物/道具；feature_film_engine._detect_era 把场景判成 古装/科幻/复古/现代 四档时代质感。
2. 社会规则行由 _核心冲突 推导（"由'{冲突}'决定人物间的相处方式与禁忌"）。
3. 声音锚点按年代查内置四档表：古装→风声+衣袂+更鼓（无现代音）、科幻→舱体低频+循环气流、复古→老物件声、现代→环境底噪。
4. 配色按 60-30-10：主色随 _视觉调性（缺省"写实"）、辅色随情绪、点缀色=首个道具的颜色。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _时间年代/_视觉调性/_核心冲突 的 JSON | 空包时 _时间年代 为空串、视觉调性回退"写实"、社会规则回退"关系" |
| 世界观深度 | 无(默认)→中(有背景设定) | 仅注入【维度配置】块，模板正文不按深度分层展开 |
| 创意方向 | 无(默认)→商业类型片 | 仅进维度块 |
| 启用反AI规则 | True | False 时跳过套话清洗 |

## 已知坑

_detect_era 只输出四档，"民国""蒸汽朋克"等年代词都落到 现代 档——声音锚点会给出"环境底噪+生活声"，与架空设定冲突；天气解析不到时时间行没有天气段（不报错，直接省略）。tests/test_all_modes.py 仅断言非空。
