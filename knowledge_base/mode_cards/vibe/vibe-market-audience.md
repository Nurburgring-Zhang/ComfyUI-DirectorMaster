## 意图

立项会需要"这片子给谁看、什么档期上、能收多少"时选它：market_audience_pro 引擎产出受众画像/档期策略/市场定位打法/票房预测/四维矩阵完整报告。与其它 Vibe 模式的本质差别：唯一不写创作的模式，输出的是数据口径的商业判断。

## 核心手法

1. 三输入 auto 时自动推断：类型按 _MARKET_GENRE_KEYWORDS 八类关键词库扫场景/核心包/情绪（爱情/喜剧/悬疑/科幻/动画/战争/动作/现实主义）；档期按类型映射（爱情→非档期、战争→国庆档、动画→春节档、其余→暑期档）；定位按创意方向关键词（短剧/小程序/爆款反转/搞笑整蛊/脑洞→黑马；商业类型片/网剧爆款/战争史诗/仙侠奇幻→头部；否则腰部）。
2. predict_box_office 四维加权：质量35% + 导演20% + 演员15% + 营销15% + 类型15% + 档期加分。
3. 三输入均支持 🎲 随机（从对应枚举真实抽选）；输出报告标注每项推断依据（用户指定/关键词命中/按类型推断）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 类型片市场 | auto（8 类枚举+🎲 随机） | 传入枚举外值时按"auto"处理→关键词推断，无命中回退"现实主义" |
| 档期策略 | auto（春节/暑期/国庆/贺岁/非档期） | 枚举外值→按类型最佳档期推断 |
| 市场定位 | auto（头部/腰部/黑马） | 枚举外值→按创意方向关键词推断 |
| 导演知名度/演员阵容/营销预算/质量评分 | 0.7 / 0.6 / 0.5 / 0.7（FLOAT 0-1 步长0.05） | ComfyUI 部件夹取 0-1；绕过 API 直传非数值时 float() 抛 ValueError，节点报错 |

## 已知坑

类型推断是纯关键词匹配——场景含"拳"即判动作片，语义误判不会提示（推断依据列会显示命中词，可据此人工复核）；该模式专用输入在其它 22 个模式下完全不被消费。
