## 意图

从零建一套可落地的品牌视觉系统时选它：输出品牌内核/标志/标准色/辅助图形/应用规范五件套的设计指令。与"海报设计"的本质差别：管跨触点复用的系统规范，不管单张传播物料。

## 核心手法

1. modes_design._build_brand_prompt：品牌系统五件套一次出齐，强调"视觉是内核外化, 不是装饰"。
2. 标志三要求：简洁（3秒记住）+独特（行业辨识）+适配（缩放/单色/反白可用）。
3. 标准色口径"主色1+辅助2，品牌情绪色，跨场景一致"；辅助图形要求可延展母题铺全触点。
4. 适配器差异点：color_tone 缺省落"品牌主色"（其余设计模式是"高对比"），style 仍为商业摄影；品牌主体/行业槽空时显示"品牌待定/行业待定"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _视觉调性 的 JSON | 空包时色彩基调落"品牌主色"（该模式专属缺省） |
| 品牌主体 | 场景解析首个人物/物件 | 空场景时显示"品牌待定"，系统无锚定对象 |
| 数量 count | 4（适配器硬编码） | 非用户参数 |
| 启用反AI规则 | True | False 时输出保留套话 |

## 已知坑

应用规范（名片/信封/包装/导视/数字）是固定清单，不按行业增删；行业槽来自场景文本而非独立输入，行业信息要写进场景描述才生效。
