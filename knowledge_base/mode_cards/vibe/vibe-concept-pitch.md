## 意图

立项前只有一句场景描述时选它：输出"一句话概念+类型+商业卖点+情感锚点+观众承诺+对标作品"六段可直接进会议室讲的 pitch。与"主题哲学"的本质差别：本模式卖故事的卖点与承诺，主题哲学挖思想的两难，不出现商业表述。

## 核心手法

1. 用 scene_engine.parse_scene 拆场景，取首个人物/首个道具/地点；缺省回退 主角/关键道具/场景。
2. 从核心数据包读 _主题词/_核心冲突/_关键道具/_观众承诺/_对标作品 五个字段（缺省：记忆/家庭/感动落泪/按导演风格与类型匹配）。
3. 套"一句话概念"句式：在{地点}, {人物}因为{道具}被迫面对'{主题}'——{冲突}在此刻被点燃。
4. 独特卖点行固定落在"情感不靠台词堆，靠道具与沉默承载"的表述上，让观众承诺（_观众承诺）收尾。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | Core 节点输出的 JSON（含 _主题词/_核心冲突/_场景描述） | 空/坏 JSON 时 parse_core_pack 返回 {}，场景与人物全用占位词，输出语法完整但信息为零 |
| 创意方向 | 无(默认)→解析为商业类型片 | 仅注入输出尾部【维度配置】块，不改模板正文；🎲 随机从 52 项抽一 |
| 情感浓度 | 无(默认)→适中(平衡) | 同上，仅进维度块，不影响概念句式 |
| 启用反AI规则 | True | 关闭后跳过 anti_ai_vocab.clean_anti_ai_text，输出保留 masterpiece/8K 类套话 |

## 已知坑

节点本身没有"场景描述"输入（INPUT_TYPES 仅 4 下拉+市场参数），场景只能来自核心数据包的 _场景描述——不接 Core 时 scene 恒为空串，pitch 里"在场景, 主角因为关键道具…"全部是占位词。tests/test_all_modes.py 的全模式非空断言拦不住这种"空转合格"输出，务必接 Core 后再用。
