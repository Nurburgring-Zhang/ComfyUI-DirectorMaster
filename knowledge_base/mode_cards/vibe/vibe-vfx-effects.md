## 意图

需要在概念阶段划定"本场哪里用特效、怎么克制"时选它：输出特效原则/本场特效点/时代适配/合成要点/克制原则五行。与"调色"的本质差别：管画面里的超现实元素合成，不管色彩与曝光。

## 核心手法

1. 特效原则行绑定主题："服务于'{主题}', 不炫技"。
2. 本场特效点从场景派生："{地点}中的超现实细节——{首个道具}的异常(光/漂浮/时间)"。
3. 时代适配行用 _detect_era 结果约束特效质感需贴合年代、避免穿帮。
4. 合成要点固定"实拍前景+CG背景, 光影方向统一, 颗粒感匹配胶片"；克制原则固定"特效出现≤3处, 每处都有叙事理由"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _主题词/_场景描述 的 JSON | 空包时主题回退"情感"、特效点回退"场景中关键道具的异常" |
| 世界观深度 | 无(默认)→中(有背景设定) | 仅注入【维度配置】块，不派生额外特效层级 |
| 启用反AI规则 | True | False 时输出保留 8K/HDR 类渲染套话 |

## 已知坑

特效点只从 objects[0] 派生一条，不产出逐镜 VFX 清单（无镜号/时长/跟踪标注），下游需自行拆解；时代适配只影响一行质感提示，不会改变特效点本身。
