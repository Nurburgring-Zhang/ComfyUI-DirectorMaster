## 意图

仪式流程的镜头化：1.0 基线密度（不干预节奏，靠场次功能自然混编）——迎宾/仪式/交换戒指/宴席的节拍由三幕骨架近似，运镜签名"婚礼运镜"统一现场感。与 演唱会纪录（钉死节奏引擎）的差别是本模式保留 auto 节奏的段落对比。

## 核心手法

- 体量推导：5-10min → get_beat_map ≥3 梯 3-6 场；density 1.0 → 分支 D target_avg=10s → 每场镜数=max(基准, 场秒/10)。
- 仪式节拍：三幕压缩近似婚礼流程——建立（迎宾/布置）、中点（仪式核心）、收束（宴席/送客）；"决定/承诺"功能场 → 对话长镜（誓言段）、"收束" → 极慢抒情（送客段）。
- 主导运镜：move="婚礼运镜" 覆写 2/3 镜；每 3 镜 1 镜原生。
- 亲密反差：婚礼场景高频命中 亲密关键词（对坐/两人/餐桌）——直觉启用时 R2 的远景克制是纪实婚礼的伦理选项。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 目标时长(分钟) | 5-10（成片） | 桶化 ≥20→30；婚礼快剪 3min 版落 ≥3 梯 3 场 |
| 节奏风格 | 无(默认)=auto | 保持 ND 让誓言长镜/送客慢镜的段落对比生效；"🎲 随机" 不生效 |
| 核心数据包 | Core 32 字段 JSON | 新人名进角色解析（c1/c2）——誓言/对视镜的 focus 主体；空输入落"主角/副线" |
| 直觉风险 | 无(默认) | R2 亲密远景（30% 触发率 medium 档）与婚礼特写预期冲突——纪实风格才启用 |

## 已知坑

- 婚礼无专属节拍表/地点池——"婚礼"语义全靠场景描述与运镜签名；流程段（迎宾/誓词/敬酒）靠剧本功能词近似。
- 1.0 密度 = 与 电影工作室 同密度档——本模式区分度只有签名 note（"5-10min 婚礼运镜"）与典型时长（d1 分簇验证点）。
- move 覆写发生在偏好之后——运镜风格_多选 弧值在非保留镜被"婚礼运镜"盖掉。
