## 意图

多镜头生成时怕"下一镜房间变样、角色左右互跳"就选它：输出空间类型/细节/角色位置/轴线/连续运动规则，目标是跨镜头的位置恒常。与"空间布局"的本质差别：管"每镜之间不变"，不管空间本身怎么分区规划。

## 核心手法

1. 空间类型行 = 地点 + 内外景（parse_scene 的 ie 字段，缺省"内"）。
2. 角色位置按固定五槽列表轮转分配：frame-left / frame-right / center / frame-left-foreground / frame-right-background——前 3 个角色各占一槽并逐行声明。
3. 连续运动按情绪三选口径：慢推/固定/环绕。
4. 硬口径：镜头停留秒数 3.0、空间稳定强度 8/10、位置可信强度 8/10（固定值）；轴线规则"角色间连线为轴, 镜头不越轴(除非情绪转折)"。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _场景描述/_情绪基调 的 Core JSON | 空包时角色回退"主角"、物件回退"关键道具"、情绪回退"孤独"（运动建议恒"慢推"路数） |
| 色彩风格_多选 | 空（单值时首值覆盖单选） | 多值>1 时输出尾追加【色彩演变弧】块，按 建置/上升/高潮/解决 分配色彩；位置/轴线规则不随阶段变化 |
| 色彩/光影/材质/构图/摄影五下拉 | 无(默认)→各自节点缺省 | 注入维度块（色彩经 COLOR_MAP 等），与位置/轴线规则无耦合 |
| 启用反AI规则 | True | False 时跳过 anti_ai_vocab 清洗 |

## 已知坑

位置分配是列表轮转不是空间推理——位置行硬上限 3 个角色（chars[:3]），第 4 个及以后角色不分配位置行，且不校验位置间物理合理性；停留 3.0s 与两个 8/10 强度是写死口径，无参数可调。tests/test_all_modes.py 曾把本模式与空间布局记为"共用模板"已知例外，V14.3 红队 P2 修复后两者模板已独立。
