## 意图

要"这一个空间本身怎么摆"的方案时选它：输出纵深设计/功能分区/空间锚点/角色动线/机位规划/视线/遮挡/光源布局八段。与"空间一致性"的本质差别（V14.3 红队 P2 修复确立）：管单空间的内部规划，不管跨镜头恒常。

## 核心手法

1. 纵深设计三档（三层：前景遮挡/中景主体/背景环境；两层：主体/背景；四层：含画框元素）——按 md5(f"{场景}_{导演}") % 3 确定性选取，同输入恒同档。
2. 功能分区四区固定：主表演区（锚点所在）/次表演区（对手位）/通道区（进出动线）/背景信息区。
3. 空间锚点=首个物件，构图围绕锚点展开；角色动线固定路径"入口→主表演区→锚点附近→情绪位"。
4. 机位三件套：A 机主机位（轴线内）/B 机侧逆（情绪位）/C 机游机（细节）；遮挡关系按情绪定窥视感/层次感，光源布局与纵深设计联动。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | 含 _场景描述 的 Core JSON | 空包时锚点回退"关键道具"、动线主角回退"主角"、内外景回退"内" |
| 导演风格 | 继承核心包 _导演风格（缺省 王家卫） | 参与纵深档 md5 计算——换导演名会翻档 |
| 色彩风格_多选 | 空（单值时首值覆盖单选） | 多值>1 时输出尾追加【色彩演变弧】块；动线/分区正文不重构 |
| 构图法则 | 无(默认)→三分法 | 仅维度块列值；正文构图由锚点+纵深决定 |

## 已知坑

纵深档由 md5(场景_导演)%3 决定——看起来随机实则确定性，想换纵深必须改场景文本或导演名；锚点恒取 objects[0]，多焦点空间不会拆锚；V14.3 修复前本模式与空间一致性共用模板（tests/test_all_modes.py 记录的已知例外），引用旧输出时注意口径差异。
