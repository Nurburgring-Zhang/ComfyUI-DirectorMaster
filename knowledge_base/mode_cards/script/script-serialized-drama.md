## 意图

剧情连续、靠每集结尾钩子驱动追更时选它。与单元剧的差别：钩子设计是"上集悬念开场直接续上 + 物件被动过"式的连续因果，结尾固定"最后 3 秒新线索或新危机"。

## 核心手法

- `SHORT_DRAMA_SUBTYPES["系列短剧"]`（script_studio.py:787）：单集 2-3 分钟、40-60 集连续剧情、爽虐甜 (4,4,2)+seed 漂移。
- 钩子池三选一：上集悬念续接 / 推门看见不该看的 / 物件换了位置（有人来过）——全部以"连续性"为前提的扰动设计。
- 字幕策略固定"前情提要 3 秒+本集标题，结尾'下集更精彩'"，卡点=每集结尾最后 3 秒。
- 第1集镜级设计（1/2/3 镜+结尾镜）随对白密度与节奏控制维度变化：零对白版第3镜无台词，极快版镜时长 2s/3s/2s。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 对白密度 | 无(默认)→标准对白 | "零对白"→对白设计行改纯画面+字幕叙事；"密集"→连珠炮质问版第3镜 |
| 节奏控制 | 无(默认)→中速 | "极快/超快"→2s/3s/2s；"极慢/慢("→5s/8s/5s |
| 主题深度 | 无(默认)→中(人物成长) | 核心包含主题词且选"深/极深/存在主义/形而上"→追加"主题不说破、结尾不给答案"陈述行 |
| 核心数据包 | Core.核心数据包 | 缺失时场景空，钩子里 loc/obj 落"场景/关键道具"占位词 |

## 已知坑

- 钩子池偏悬疑扰动母题，写甜宠向连续剧时"物件换了位置"类钩子会偏惊悚感——模板不按题材二次适配。
- 短剧系目标时长参数不消费（单集 2-3 分钟来自子类型表），误设"目标时长 90 分钟"不会变成长片。
- 真实案例库/故事感总纲注入走"短剧"关键词匹配，本模式名含"短剧"命中；库 import 失败时静默缺块。
