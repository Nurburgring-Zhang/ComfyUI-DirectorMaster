## 意图

每集靠"最后一秒认知颠覆"留住观众时选它。与爽剧的差别：驱动力是信息差而非情绪压制——钩子在"细节不对"，卡点在"真正的主人另有其人"式的身份/归属颠覆。

## 核心手法

- `SHORT_DRAMA_SUBTYPES["反转小程序"]`（script_studio.py:739）：定位"每集一个认知颠覆，结尾必反转"、单集 60 秒、总集数 50-80、爽虐甜 (4,3,3)。
- 钩子池三选一：笃定判断+镜头切到不对的细节 / 所有人都信了除了主角 / 开场即结局然后倒放——全部为反转埋信息差。
- 卡点"最后一秒反转：{obj}真正的主人另有其人"；字幕"倒计时字幕压迫感，反转帧闪白+音效抽离"。
- inject_library_depth 关键词表（短剧/短视频/微短剧/钩子/反转）显式含"反转"——本模式命中两条注入：故事感总纲+真实短剧案例。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 对白密度 | 无(默认)→标准对白 | "零对白"→纯画面+字幕叙事；反转信息全靠画面细节承载 |
| 节奏控制 | 无(默认)→中速 | "极快/超快"→2s/3s/2s；60 秒集体量下快档更贴合反转节奏 |
| 主题深度 | 无(默认)→中 | 核心包含主题词+"深/极深"→主题陈述行追加（反转剧一般用不到深档） |
| 核心数据包 | Core.核心数据包 | 缺失时卡点落"关键道具真正的主人另有其人"，失去具体性 |

## 已知坑

- 反转母题固定在"物件归属"维度，写人物身份反转（间谍/双胞胎）需换钩子池或人工改卡点。
- 开场即结局的倒放钩子是文案级设计，本节点不产出实际倒放的镜序——执行层由 Cinematic 节点承接。
- 目标时长不消费；60 秒/集与 50-80 集为子类型表硬编码。
