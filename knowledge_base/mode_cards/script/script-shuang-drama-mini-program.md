## 意图

要"一集一个爽点、看完就付费"的强情绪小程序剧时选它。与竖屏小程序剧通用形态的差别：爽虐甜 (6,2,2) 爽占绝对大头，钩子直接从羞辱现场切入，三秒内给出反转预兆。

## 核心手法

- `SHORT_DRAMA_SUBTYPES["爽剧小程序"]`（script_studio.py:747）：定位"情绪直给，一集一个爽点闭环"、单集 90 秒、总集数 80-100。
- 钩子池三选一：被当众羞辱三秒后对方跪了 / 物件一出现全场起立 / 只说一个字对面腿软——全部是"即时权力反转"结构。
- 卡点"{c1}亮出底牌——此前所有轻视加倍奉还"；字幕"大号加粗字幕，爽点处屏幕震动特效"。
- 第1集镜级三档：默认 3s/5s/3s；"极快/超快"压到 2s/3s/2s 并标注卡点更密。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 对白密度 | 无(默认)→标准对白 | "零对白"会消解"一个字震慑"钩子的对白依赖，输出自动改写为手部动作+眼神版 |
| 节奏控制 | 无(默认)→中速 | "极快/超快"→2s/3s/2s；"极慢/慢("→5s/8s/5s（爽剧不推荐，卡点密度下降） |
| 潜文本强度 | 无(默认)→中 | 选零→删潜文本行；爽剧直给逻辑下该行本就弱化 |
| 核心数据包 | Core.核心数据包 | 缺失时占位词进钩子（"关键道具一出现，全场起立"）——输出合法但失真 |

## 已知坑

- 爽基线 6 随 seed%3 漂移为 6-8，虐恒 2、甜 0-2：数字抖动不影响定位但影响投放文案一致性。
- 钩子母题（跪/腿软/起立）强度极高，写职场/商战以外的题材（如古风）时权力符号需人工校准。
- 真实短剧案例库注入按"爽剧"不在关键词表（短剧/短视频/微短剧/钩子/反转）——实际命中"短剧"子串，注入正常；库缺失时静默无块。
