## 意图

单人物深潜的 60-90 分钟纪录片：先"看见"（观察式长镜进入日常），再让核心事件自己浮现。与社会纪录片的差别：单视角个案深潜而非多视角议题交叉，冲突来自真实而非设计。

## 核心手法

- `FORMAT_SCENE_SKELETONS["人物纪录片脚本"]`（script_studio.py:1059）5 槽：观察式长镜·人物日常→核心事件浮现→采访穿插·内心揭示→选择时刻·冲突可见→开放结尾·判断留给观众；75min 出 18 场，5 槽比例映射。
- 执行层纪录片族分支逐场标注机位与采访问题（"当时你为什么那样选？/那一刻你在想什么？/本场无采访"三选一）。
- 槽位 mission 硬约束："不摆拍，不采访先行""冲突来自真实而非设计""旁白克制，让人物自己说""不给结论"。
- `FORMAT_MODE_FLAVOR`（:923）：观察式长镜+采访穿插、人物日常→核心事件→内心揭示三段递进。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 目标时长(分钟) | 0（自动→75） | 显式 60→15 场、90→25 场；≥110 归 120 桶 |
| 对白密度 | 无(默认)→标准对白 | 采访段落即对白载体；"零对白"档输出纯观察结构（可用，但采访槽失效） |
| 叙事编排 | 无(默认)→跟随叙事结构 | "穿插倒叙"与纪录片的闪回互文契合——重排失败时 stderr 降级保原序 |
| 核心数据包 | Core.核心数据包 | 人物信息靠场景解析；核心包缺失时角色回落"主角/副线"，纪录感削弱 |

## 已知坑

- "不摆拍/冲突来自真实"是创作纪律声明，引擎生成的事件仍是结构化产物——纪实性靠实拍验证，脚本只保证结构位。
- 18 场对 5 槽的映射使"日常"槽覆盖约 4 场，长观察段需要人工在引用时展开。
