## 意图

只要结构不要正文的开发阶段卡：三幕各给场景/钩子/转折/物件承载/潜文本/情绪递进。与剧本正文的差别：无对白无场次头——是给编剧看的一页纸骨架，不是给拍摄看的台本。

## 核心手法

- `_build_architecture_template`（script_studio.py:506）：三幕固定框架（第一幕建立 0-30min / 第二幕对抗 30-70min / 第三幕解决 70-90min），场景元素来自 parse_scene（c1/c2/第一物件/地点）。
- seed=md5(场景_导演_arch)：钩子 3 选一（动作突然停顿/物件出现在不该在的位置/地点声音先于画面）、转折 3 选一（对手做没料到的事/物件真相露一角/旧话重提）；高潮句固定模板"第一次正面回应一直回避的事——但用的是最平常的方式"。
- 每幕注入剧作功能标注：潜文本（有话没说，用日常动作掩盖）、物件承载（{obj}承载未说出的事）、情绪递进（困惑→对抗→动摇→理解）、留白结尾（用一个动作完成和解，不说一句话）。
- strip_decor 版被 `_build_full_screenplay`（:1488）并入长片/形态模式尾部——架构卡同时是全节点的结构公共件。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 核心数据包 | Core.核心数据包 | `_integrate_5d_into_screenplay_content`（:495-496）对"剧本架构"模式特判【5 维锚定】头块（无装饰条带版）；连接创意/美术输入时锚定先行 |
| 目标时长(分钟) | 0（自动→120） | 三幕的 0-30/30-70/70-90min 标注为固定文本，不随时长缩放 |
| 叙事结构 | 无(默认)→三幕剧(经典) | 模板即三幕——下拉不改变骨架分幕 |
| 情绪基调 | 继承核心包 | 进卡片头行"情绪: {mood}" |

## 已知坑

- 幕时长标注（0-30/30-70/70-90min）与目标时长参数完全脱钩——写 5 分钟短片时结构标注仍显示 90 分钟口径，引用需人工换算。
- 只有两幕转折位可 seed 抖动，第三幕高潮/留白固定模板——同场景多次运行仅前两幕微变。
- 双角色假设：c2 缺失时兜底"对手"，单人独角戏场景会出现幽灵对手。
