## 意图

短平快的产品/宣传广告：3 场结构是本节点所有模式里最短的。与品牌故事片的差别：直接卖点递进 + 行动号召，不做人物情感叙事；品牌在前 3 秒刻意不出现、结尾才露出。

## 核心手法

- `FORMAT_SCENE_SKELETONS["广告宣传片脚本"]`（script_studio.py:1039）3 槽：前3秒抓注意→卖点呈现(≤3个)→CTA行动号召；1min 下场景数=3，是骨架覆盖的最小场数档。
- 执行层广告分支（:1213-1217）逐场标注卖点证明方式：使用前后对比/细节微距证明/真实场景证言三选一（seed 含模式名，与品牌故事片共用分支代码但 seed 不同）。
- 槽位 mission 硬约束："品牌先不出现""每个卖点用一个可验证的画面证明""一句话说清现在该做什么"。
- 1min ≤3 → 追加 AIGC 五段结构块（时间拍按总秒数均分，核心包缺 `_成片秒` 时兜底 30s）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 目标时长(分钟) | 0（自动→1） | 显式 >24 → 退出 3 槽覆盖走时长阶梯；15s 级输入（0.25）仍 3 场，场内时长感靠文本 |
| 对白密度 | 无(默认)→标准对白 | 广告口播为主："零对白"档删除对白行后 CTA 依赖字幕文案 |
| 潜文本强度 | 无(默认)→中 | 广告直给，建议零档——潜文本行会稀释卖点信息密度 |
| 核心数据包 | Core.核心数据包 | 卖点内容须写进场景描述；核心包缺失时"产品/品牌载体"落占位物件 |

## 已知坑

- 3 场是硬下限结构：写多卖点长广告（60s 以上多信息层）时槽位不扩，需人工加场。
- 卖点"≤3 个"是约定文本，引擎不校验场景描述里写了几卖点——超量输入不会被截断。
