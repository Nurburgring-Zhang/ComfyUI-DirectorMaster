## 意图

观众选择驱动剧情的互动剧：选择点的差异必须是价值观差异而非信息差异。与所有线性模式的差别：输出额外附一段可解析的分支树 JSON（N0→N1→N1A/N1B→N2→E1/E2/E3），选项带代价与价值轴标注。

## 核心手法

- `FORMAT_SCENE_SKELETONS["互动剧分支剧本"]`（script_studio.py:1075）5 槽：主线建立·节点N0→选择点一·分支展开→分支发展·后果分化→汇合点或二次选择→多结局收束；30min 默认走时长阶梯出 8 场（>24 不用骨架场数）。
- `_build_interactive_branch_tree`（:1263）确定性生成分支树 JSON：围绕核心物件的价值观四选二（诚实/保护/信任/决绝），N1 双选项→N1A/N1B 后果分化（不可互换）→N2 汇合二次选择（2-3 选项）→E1/E2/E3 三结局；stats 字段自报 8 节点/2 选择点/3 结局/分支深度 2。
- 执行层互动剧分支（:1224-1229）逐场标注节点号 N{i} 与选项设计（2选项安全/冒险、2选项诚实/隐瞒、3选项含隐藏项三选一）。
- 分支树追加于完整正文尾部（:1511-1516），生成异常时 stderr 写"[DirectorMaster] 分支树生成降级"，正文不受影响。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 目标时长(分钟) | 0（自动→30） | 30→8 场；>24 恒走阶梯不动骨架场数；≤24 时场景数=5 槽 |
| 对白密度 | 无(默认)→标准对白 | 分支树 JSON 不受对白密度影响（独立生成）；只影响正文场次对白 |
| 潜文本强度 | 无(默认)→中 | "强"档每场潜文本行会与选项代价文案重复表意，建议中/弱 |
| 核心数据包 | Core.核心数据包 | 分支树的抉择对象=场景解析出的第一个物件（obj），核心包缺失时回落"关键道具" |

## 已知坑

- 分支树节点/选项是模板池确定性生成——换场景描述换 seed 可得不同组合，但同场景重复运行结果恒定（无随机数注入）。
- 30min 与"5 槽"骨架是两个口径：8 场正文 + 5 结构位标签按比例映射，N0-N2 节点号只出现在执行层标注里，与 JSON 树的 N0/N1/N2 同名但粒度不同。
