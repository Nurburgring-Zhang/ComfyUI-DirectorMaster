## 意图

只产出一段双人潜文本对白示范：3 组往来对白各带〔潜文本〕行解注。与剧本正文的对白区别：这里对白即全部产出——练习"每句≤10 字、真话只说一半、物件代替语言"的三原则。

## 核心手法

- `_build_dialogue_template`（script_studio.py:656）：角色取 parse_scene 前两名（c2 缺失兜底"副线"），物件取第一个解析道具；固定 3 组对白模板插值（"来了。/嗯。"→"那个{obj}.../怎么了?/没什么。"→"一直留着?/...习惯了。"）。
- 每组对白后跟潜文本解注行（"想说的远比说出口的多""话到嘴边又咽下，{obj}承载着没说出的事""'习惯了' = 一直记得"）。
- 尾部【对白原则】固定三条：每句≤10 字、真话只说一半、物件代替语言。
- 5 维锚定特判：`_integrate_5d_into_screenplay_content`（:497-499）对"对白大师"模式把角色锚定（姓名/性格/外貌/服装）以【5 维锚定】头块注入——连接角色输入时对白人物与角色圣经对齐。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色输入 | 空（可选） | 连接后 `_parse_char_anchors`（:411）解析"姓名:/性格:/外貌:/服装:"行注入锚定块；缺"姓名:"行则整块为空 |
| 潜文本强度 | 无(默认)→中 | 本模板对白/解注行固定——该下拉不改写示范内容，只在维度 footer 声明 |
| 对白密度 | 无(默认)→适中 | 同上：模板即极简对白，下拉不重写 |
| 核心数据包 | Core.核心数据包 | 无解析物件时 obj 落"那件东西"占位，第三组对白失焦 |

## 已知坑

- 群像场景只取前两个角色——三人以上对话需自行扩展，模板结构固定双人。
- 潜文本强度下拉在本模式"声明但不生效"（示范行固定），与其他剧本模式行为不同——引用时勿期待分档差异。
- 角色输入锚定要求逐行含"姓名:"/"性格:"等键名（半角冒号），全角冒号或不同键名解析为空。
