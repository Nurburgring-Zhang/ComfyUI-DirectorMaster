## 意图

男频逆袭（战神/赘婿/马甲大佬）竖屏剧立项时选它。与女频甜宠的差别：爽虐甜配比 (7,3,0) 甜为零，全部爽点驱动，节奏是"被轻视→当场打脸"的循环。

## 核心手法

- `SHORT_DRAMA_SUBTYPES["男频逆袭竖屏"]`（script_studio.py:723）：定位"爽点驱动，被轻视→当场打脸"、单集 90 秒、总集数 80-100。
- 钩子池三选一：众人嘲笑他不抬头 / 物件摔地眼神变了 / 一句"你配吗"他缓缓掏出手机——都把羞辱前置到第 1 镜。
- 卡点固定"{c1}真实身份曝光——全场鸦雀无声"；字幕策略"金色爆裂字幕，打脸瞬间慢放+重低音"。
- 节奏控制"极快/超快"时第 3 镜改写为连珠炮质问（对白密度密集分支）或无台词手抖（零对白分支），镜时长 2s/3s/2s。

## 已知坑

- 爽虐甜 (7,3,0) 中甜=0：漂移公式 s+ep1 : n : max(0,t-ep1) 使甜恒为 0、爽在 7-9 之间——数字按 seed 抖动，文案定位不变。
- 钩子池含"掏出手机"等现代意象，古装逆袭题需在场景描述写清年代器物，否则插值违和。
- 目标时长参数不消费；真实案例库/故事感总纲注入依赖库 import 成功，缺失静默。
