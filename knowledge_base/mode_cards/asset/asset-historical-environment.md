## 意图

民国/古代等明确年代背景建卡时选它。与"奇幻场景"的差别：考据导向——建材/照明/交通工具年代准确、画面无现代痕迹穿帮、人群仪态符合时代。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["历史环境"]` 三条（年代考据/无现代穿帮/仪态符合时代）。
2. 环境描述留空→场景描述→parse_scene 地点词（"古镇/客栈/宫廷/租界/外滩/百乐门"等历史词命中）→空串。
3. 场景内道具行核心物件前 4；环境锚定按导演定主色（历史题材常配特定色彩导演）、按情绪定光影。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填年代与街区 | 留空且无核心包→环境描述行空串，年代信息无处着落 |
| 环境类型 | 室外/室内按场景 | 类型槽与年代无联动；填"太空"照常输出考据指令 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"上海/北平/天津"映射到街巷锚（V16.1 修复）；不接→道具行"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；年代质感全靠文本，现代物穿帮风险升高 |

## 已知坑

- 年代考据指令不含具体年代库——"哪个年代"必须写进环境描述或核心包场景，卡面不会自动推年代。
- "租界/百乐门"等词只在词表命中时才进地点锚，自造年代词（"1937")不解析。
