## 意图

都市夜景/商业区/城中村建卡时选它。与"室外环境"的差别：指令三条聚焦城市专属要素——招牌管线空调外机的信息密度、人流节奏与主角节奏相反、夜色混合色温。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["城市环境"]` 三条（信息密度/人流反节奏/混合色温）。
2. 环境描述留空→场景描述→parse_scene 地点词（"便利店/写字楼/夜市/广场"等城市词命中；"上海/北平"等城市名映射到街巷锚）→空串。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调光影——城市夜景常配混合色温导演（如王家卫）。
4. 一致性策略统计环境母版数并输出跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填街区细节 | 留空且无核心包→环境描述行空串，只剩城市指令撑卡 |
| 环境类型 | 室外（城市多为室外） | 类型槽与模式无联动校验，填"室内"照常输出城市指令 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"上海"命中映射"上海街巷"（V16.1 修复防"海"误判海边）；不接→道具行"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0，霓虹混合色温难靠文本稳定复现 |

## 已知坑

- parse_scene 城市名匹配有同长优先级规则（"后台"胜过"上海"），场景词同时含两者时地点锚取前者——城市卡地点行可能不是城市名。
- 人流节奏/色温属于拍摄执行层指令，本卡只输出文本，不会传导到下游视频路由参数。
