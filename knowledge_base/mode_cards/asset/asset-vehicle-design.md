## 意图

给有戏份的车辆/飞船/船只建卡时选它。指令三条：内饰磨损匹配车龄、声音特征先行（引擎/铃铛）、涂装有地域与年代依据——载具是"会动的道具"。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["交通工具设计"]` 三条（内饰磨损/声音先行/涂装依据）。
2. 清单装配走服化道分支继承链：载具写进服化道描述；留空→_关键道具+场景物件继承。
3. 角色绑定行取核心角色前 3——载具与驾驶者绑定；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头外观/材质锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填车型/涂装/车龄 | 留空→清单继承场景物件；两头空→"未指定"+占位提示词 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"电动车/飞船/轮船"命中 parse_scene 地点表会把载具映射成空间锚（车内/船上）——注意载具名进描述而非仅进场景 |
| 视觉风格 | 写实 | 进提示词行；"🎲 随机"→系统随机 8 选 1 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；车身反射/涂装跨镜一致性差 |

## 已知坑

- parse_scene 里"电动车"→"街巷"、"车"→"车内"：描述含车名会改变地点锚——环境卡与载具卡的地点行可能互不一致。
- "声音特征先行"执行在声音侧，本卡只输出文本。
