## 意图

为主角/主要配角定一套可跨镜头复现的服装时选它。与"服化道设定"总卡的差别：指令聚焦服装单品类——穿在身上的前史、60/30/10 配色法则、磨损位置符合人物职业。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["服装设计"]` 三条（服装前史/主辅点缀 60-30-10/磨损对位职业）。
2. 清单装配走服化道分支继承链：描述留空→_关键道具+场景物件合并；服装的具体设计需用户写进描述（如"褪色蓝工装"）。
3. 角色绑定行取核心角色前 3——服装与穿它的人关联；一致性策略统计道具母版数（服装母版接"参考图_道具母版"槽）。
4. 生成提示词行按视觉风格+材质纹理+情绪组装。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填服装清单与配色 | 留空→清单被场景物件占位（灶台/碗柜等），服装设计名不符实 |
| 核心数据包 | Core 输出 JSON 包 | 不接→角色绑定行消失，服装与人物脱钩 |
| 视觉风格 | 写实 | 进提示词行；"🎲 随机"→系统随机 8 选 1 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；60/30/10 配色靠文本锚，色相漂移常见 |

## 已知坑

- 本模式与化妆/道具等共用同一分支与输出骨架，唯一差异是设计指令块——服装的具体设计内容全靠描述槽自写，卡面不会生成服装款式。
- 服装母版要接"参考图_道具母版"槽（节点无服装专属槽），ref_block 里该图标注为"道具母版 (外观/材质/年代锁定)"。
