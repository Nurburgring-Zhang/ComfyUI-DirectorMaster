## 意图

硬科幻/太空歌剧背景建角色卡时选它。与"未来角色"的差别：服装池是 `_ERA_WARD["科幻角色"]`（"轻量化装备, 磨损掉漆, 有使用痕迹"）——强调用旧的真实感，叙事定位强调"科技装备逻辑自洽, 功能可解释"。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["科幻角色"]`。
2. 时代衣冠补全：服装留空→_ERA_WARD 命中，输出轻量化装备/磨损掉漆/使用痕迹，对齐"科技有使用痕迹"的科幻一致性原则。
3. 姓名继承首位；性格/外貌走通用种子池。
4. 三视图锚定 + 表情变体；道具绑定核心物件首项（科幻题材常绑定界面/装备类物件）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色服装 | 留空走 _ERA_WARD["科幻角色"] | 填值原样使用；填崭新盔甲文案与"使用痕迹"定位冲突，不会被纠偏 |
| 视觉风格 | 写实 | "🎲 随机"→系统随机 8 选 1，非种子确定性 |
| 角色性格 | 留空走通用池 | 无科幻专属性格池；装备与性格的关联需手写 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"太空/宇宙/飞船"命中 parse_scene 地点表；不接→无道具绑定 |

## 已知坑

- 与"未来角色"仅服装池和叙事定位不同，卡面骨架相同——选错模式产出差异不大，互审时按叙事定位行区分。
- 通用外貌池为写实系，义体/改造特征需手填。

- 数据来源：_ERA_WARD 内联字典；核心数据包→aggregator/scene_engine.py :: parse_scene
