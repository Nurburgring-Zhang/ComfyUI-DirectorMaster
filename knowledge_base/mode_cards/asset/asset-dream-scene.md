## 意图

梦境/幻觉/意识流段落建卡时选它。指令三条给"梦感"可拍定义：空间连续性可断裂、熟悉场景的陌生化变形、光线无来源——区别于奇幻场景的"自洽规则"，梦境规则就是失效。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["梦境场景"]` 三条（空间断裂/陌生化/光线无来源）。
2. 环境描述留空→场景描述→parse_scene 语义兜底（描述含"梦"或 dream→地点锚"梦境"）→空串；梦境描述建议写"熟悉场景 + 变形点"。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调光影。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 必填"熟悉场景+变形" | 留空且无核心包→环境描述行空串；描述含"梦"字地点锚才命中"梦境" |
| 环境类型 | 虚拟/室内按内容 | 类型槽与梦感无联动校验 |
| 核心数据包 | Core 输出 JSON 包 | 不接→道具行"无"；梦中物件建议写进 _关键道具 |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；梦境本就允许变形，母版约束力低于现实系模式 |

## 已知坑

- parse_scene 的"梦境"锚只在描述含"梦/dream"时触发，纯描述（"漂浮的卧室"）不命中，地点行退"按场景描述"。
- "光线无来源"与写实模式"自然光优先"互斥——同一场景在两模式间切换会得到矛盾指令，按叙事段落选模式。
