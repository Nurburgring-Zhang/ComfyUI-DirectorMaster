## 意图

空间站/飞船舱内建卡时选它。与"科幻场景"的差别：指令三条是太空物理专属——零重力漂浮细节（头发/水滴/衣物）、舱壁冷光与舷外深空对比、设备指示灯是唯一暖色。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["太空环境"]` 三条（零重力细节/冷光对比/指示灯暖色）。
2. 环境描述留空→场景描述→parse_scene 地点词（"太空站/空间站/飞船/生态站/植物舱"命中）→空串。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调光影。
4. 一致性策略统计环境母版数，输出跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填舱段布局 | 留空且无核心包→环境描述行空串 |
| 环境类型 | 太空（下拉含此值） | "🎲 随机"→系统随机 5 选 1，可能抽到"水下"与零重力指令冲突 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"太空/飞船"命中地点表；不接→道具行"无"、导演固定"王家卫" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0，舱内几何透视纯靠文本锚极易漂移 |

## 已知坑

- 类型槽"太空"与本模式指令对齐，但环境类型选择不改变指令内容——指令块只由模式名决定。
- 零重力物理表现是生成模型高频失败点，本卡仅文本提示，不附带负面提示词块。
