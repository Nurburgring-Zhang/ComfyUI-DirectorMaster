## 意图

废土/灾变后世界建卡时选它。指令三条抓住末世辨识度：文明残骸的具体物件（半块招牌/锈蚀车辆）、植被 reclaim 人造物、天空永远不干净。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["末世环境"]` 三条（残骸物件/植被侵蚀/脏天空）。
2. 环境描述留空→场景描述→parse_scene 地点词→空串；末世常无专属地点词，描述行承载"哪座城市的废墟"信息。
3. 场景内道具行核心物件前 4——残骸道具（锈蚀车辆等）建议写进核心包 _关键道具 进入此行。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 必填废墟构成 | 留空且无核心包→环境描述行空串，只剩三条指令撑卡 |
| 环境类型 | 室外 | 类型槽与指令无联动；"🎲 随机"→系统随机 5 选 1 |
| 核心数据包 | Core 输出 JSON 包 | _关键道具 首段会替代空物件表进"场景内道具"行；不接→"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；废墟层叠结构文本锚难保跨镜一致 |

## 已知坑

- "植被 reclaim 人造物"等指令含英文混排，逐字进入输出——下游若按纯中文分词会拆碎。
- 末世物件残骸与"特殊道具"模式分工：叙事触发器道具建卡走特殊道具，环境级残骸留在本模式描述行。
