## 意图

给历史/民国/古代戏的道具（油灯/电报机/瓷碗）建卡时选它。与"时代道具"近邻"历史环境"分工：环境管空间考据，本模式管道具考据——材质/印刷/工艺、旧化三层（全新库存/常用/废弃）、防穿越感穿帮。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["时代道具"]` 三条（材质工艺考据/旧化分层/防穿越）。
2. 清单装配走服化道分支继承链：道具与年代写进服化道描述；留空→_关键道具+场景物件继承。
3. 角色绑定行取核心角色前 3；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填道具+年代+材质 | 留空→继承场景物件（年代不明），考据无从谈起 |
| 核心数据包 | Core 输出 JSON 包 | 不接→角色绑定行消失、无清单继承 |
| 视觉风格 | 写实/水墨 | 进提示词行；"🎲 随机"→系统随机 8 选 1 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；工艺细节（釉面/纸纹）靠文本锚易失真 |

## 已知坑

- 年代信息（"民国十二年"）无结构化解析——写进描述原文直出，不会自动换算或校验。
- 与"历史环境"模式共用 parse_scene 历史地点词，但道具与环境的考据各自独立建卡，无跨卡联动。
