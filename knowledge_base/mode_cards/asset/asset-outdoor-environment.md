## 意图

街道/院子/郊野等开放空间建卡时选它。与室内模式的差别：设计指令三条为"天气作为情绪参与叙事 / 地面材质反光控制 / 远景天际线压缩或释放情绪"，把天气当叙事变量。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["室外环境"]` 三条（天气参与叙事/地面反光/天际线情绪）。
2. 环境描述留空→场景描述→parse_scene 地点词（"街道/巷子/庭院/码头"等室外词命中）→空串。
3. 场景内道具行核心物件前 4；环境锚定块：主色调按导演、光影按情绪基调——室外天气词（雨/雪）同时会被 parse_scene 时间/天气解析捕获。
4. 一致性策略统计环境母版数，输出跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填具体空间 | 留空且无核心包→环境描述行输出空串 |
| 环境类型 | 室外 | "🎲 随机"→系统随机 5 选 1，可能抽到"室内"与指令块天气叙事冲突 |
| 核心数据包 | Core 输出 JSON 包 | 场景含"雨夜/雪"时情绪基调与天气行联动；不接→道具行"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0，天际线/反光全靠文本锚 |

## 已知坑

- parse_scene 天气解析仅识别有限词表，"阴天/雾"等描述不进结构化锚，只留在环境描述行。
- 与"自然环境"模式的指令池不同（室外偏人造物与天际线，自然偏风声水声与植物层次）——城郊结合场景按主导元素选模式。
