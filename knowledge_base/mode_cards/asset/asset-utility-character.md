## 意图

给只出场几次、但要在关键节点推剧情的功能人物（线人/店主/快递员）建卡时选它。与其他角色模式的差别：叙事定位强调"用一个细节让人记住"，模式本身定位轻量——分支行为与配角一致，仅定位文案不同。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["工具人角色"]`（"功能人物 — 关键节点出场推动情节, 用一个细节让人记住"）。
2. 缺槽确定性补全：性格/外貌/服装走通用种子池——工具人往往懒得细写，补全池产出"眼下青黑, 强撑精神"式可拍细节。
3. 道具绑定：核心物件首项"出场必带"，让功能人物与关键道具产生记忆关联。
4. 三视图锚定块照常输出，供该角色少量镜头的一致性锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色名 | 主角 | 留默认且核心场景有人物→被解析首位替换；工具人建议显式填名避免与主角撞名 |
| 角色外貌 | 留空走 _LOOK_TRAITS | 填值原样使用；留空→种子补全一条外貌细节 |
| 核心数据包 | Core 输出 JSON 包 | 不接→道具绑定行消失，卡片缺"出场必带"锚 |
| 视觉风格 | 写实 | 进生成提示词行；"🎲 随机"→系统随机非确定 |

## 已知坑

- 本模式与"配角角色"共用同一分支，输出差异仅叙事定位一行；指望更简化的卡面结构落空。
- 三视图锚定对只出场一两镜的工具人是过度产出，下游多镜头模板会照单全收。
