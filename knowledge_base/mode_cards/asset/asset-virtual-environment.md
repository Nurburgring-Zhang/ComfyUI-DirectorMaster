## 意图

赛博空间/游戏世界/数字意识流建卡时选它。指令三条暴露"非真实"的视觉语言：网格粒子暴露虚拟边界、物理规则可局部失效、色彩过饱和暗示非真实。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["虚拟环境"]` 三条（虚拟边界/物理局部失效/过饱和）。
2. 环境描述留空→场景描述→parse_scene 地点词→兜底语义锚（"梦"映射"梦境"）→空串。虚拟空间常无现实地点词，描述行几乎必填。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 必填虚拟空间规则 | 留空且无核心包→环境描述行空串，虚拟空间无地点词兜底可用 |
| 环境类型 | 虚拟（下拉含此值） | 类型槽仅显示行；"🎲 随机"→系统随机 5 选 1 |
| 核心数据包 | Core 输出 JSON 包 | 不接→道具行"无"；虚拟物件通常不在 parse_scene 物件表内 |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；网格/粒子风格漂移率高 |

## 已知坑

- parse_scene 地点词表以现实空间为主，纯虚拟描述（"数据流中"）无词可命中，地点行退回"按场景描述"或语义兜底锚。
- "物理局部失效"是渲染层需求，本卡只输出指令文本，不会改写下游视频模型的物理参数。
