## 意图

给有戏的食物（夜市摊/家宴/定情餐）建卡时选它。指令三条：热气/油光是生命力、食用动作设计、食物与人物关系互文——食物是情绪载体。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["食品设计"]` 三条（热气油光/食用动作/人物互文）。
2. 清单装配走服化道分支继承链：食物写进服化道描述；留空→_关键道具+场景物件继承。
3. 角色绑定行取核心角色前 3；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填菜品与状态 | 留空→清单继承场景物件；两头空→"未指定"+占位提示词 |
| 核心数据包 | Core 输出 JSON 包 | 不接→角色绑定行消失，"食物与人物互文"无从落地 |
| 视觉风格 | 写实 | 食物对风格最敏感（日漫 vs 写实油光完全不同）；"🎲 随机"非确定 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；食物形态跨镜漂移率极高 |

## 已知坑

- 食用动作属于表演设计，输出为文本指令，执行在角色表演/分镜侧。
- 热气/油光是动态效果，静态参考图锁不住，需视频侧提示配合。
