## 意图

给承担叙事转折的道具（钥匙/录音带/契约书）建卡时选它。与"道具设计"的差别：指令明确"出场即悬念"的触发器定位，并要求可复制多份供拍摄损耗、机关/发光部件提前测试。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["特殊道具"]` 三条（叙事触发器/复制备份/机关提前测试）。
2. 清单装配走服化道分支继承链：特殊道具写进服化道描述；留空→_关键道具+场景物件继承——核心包关键道具最该走本模式建卡。
3. 角色绑定行取核心角色前 3；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填触发器道具与机关 | 留空→继承普通物件，特殊道具卡失去触发器焦点 |
| 核心数据包 | Core 输出 JSON 包 | _关键道具 首段同时进角色卡道具绑定行——道具与角色卡自动互链 |
| 视觉风格 | 写实 | 发光/机关部件与写实风格需在描述里写明发光逻辑 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；悬念道具跨镜变形会打断叙事识别 |

## 已知坑

- "可复制多份"是实体拍摄指令，AI 生成侧无损耗概念——该指令输出后对视频模型无直接作用。
- 机关/发光细节写得越含糊生成越不稳定，描述里写清"何时亮/怎么亮"。
