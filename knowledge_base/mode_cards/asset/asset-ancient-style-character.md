## 意图

拍古代背景、要求衣冠即身份时选它。与其他角色模式的差别：服装留空时走 `_ERA_WARD["古风角色"]` 时代衣冠池（"宽袖长袍, 腰封革带, 布料纹理粗粝真实"），而不是通用服装池。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["古风角色"]`（"礼仪/称谓/举止符合时代, 衣冠即身份"）。
2. 时代衣冠补全：服装留空→_ERA_WARD 命中本模式键，直接输出宽袖长袍/腰封革带/布料纹理描述，保证朝代质感下限。
3. 姓名继承与性格/外貌补全同单角色分支（通用池，无古风专属性格池）。
4. 三视图锚定的背面视图提示词写"服装后片完整"——古风宽袍后片形制是 IP-Adapter 背面锁定的高风险漂移点。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色服装 | 留空走 _ERA_WARD["古风角色"] | 填值原样使用；填现代服装文案不会被纠偏，穿帮风险自担 |
| 视觉风格 | 写实 | 配水墨/赛璐璐可强化古风；"🎲 随机"→系统随机 8 选 1，可能抽到 3D CG 与古风定位冲突 |
| 角色性格 | 留空走通用池 | 本模式无专属性格池；礼仪举止要靠用户在性格槽自写 |
| 核心数据包 | Core 输出 JSON 包 | 场景描述含"古镇/宫殿/客栈"等词时 parse_scene 地点锚定命中，出场场景行不再空泛 |

## 已知坑

- _ERA_WARD 只覆盖 古风/未来/科幻/奇幻/现代 5 键；工具人/配角等模式留空服装走通用池——想给配角古装要直接用本模式。
- 补全池种子含项目名与模式名，跨模式建同一古风角色时服装补全不一致（通用池卡 vs 衣冠池卡）。

## 节点映射

- 实现文件：aggregator/asset_master.py

- 数据来源：_ERA_WARD 内联字典；核心数据包→aggregator/scene_engine.py :: parse_scene
