## 意图

巨树/浮岛/魔法都市等超现实世界建卡时选它。与"末世/历史"的差别：尺度可以夸张（巨树/浮岛），但要求生态链与超自然光源"有规则"——幻想不等于随意。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["奇幻场景"]` 三条（物理尺度夸张/自洽生态链/光源可超自然但有规则）。
2. 环境描述留空→场景描述→parse_scene 地点词→语义兜底（"梦"→梦境）→空串；奇幻地名多不在现实词表，描述行必填度高于现实系模式。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调光影。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 必填奇幻地理规则 | 留空且无核心包→环境描述行空串，"自洽"无从落地 |
| 视觉风格 | 写实/水彩 | "🎲 随机"→系统随机 8 选 1，可能抽到与幻想违和的风格 |
| 核心数据包 | Core 输出 JSON 包 | 不接→道具行"无"、导演固定"王家卫"；奇幻物件建议写进 _关键道具 |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；巨型尺度透视最依赖母版 |

## 已知坑

- 与"奇幻角色"模式配套但词池独立（场景指令不含服饰内容），两卡各建各的，无跨卡联动字段。
- "光源可超自然但有规则"的规则本身要写在描述里，卡面不生成规则文本。
