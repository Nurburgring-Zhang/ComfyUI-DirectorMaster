## 意图

给科幻/未来戏的手持科技（终端/注射器/翻译器）建卡时选它。与"科幻场景"分工：场景管空间，本模式管手持级科技——功能一眼可读、界面光色统一世界观、保留物理按键的触感。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["未来道具"]` 三条（功能可读/界面光色统一/物理按键触感）。
2. 清单装配走服化道分支继承链：道具与功能写进服化道描述；留空→_关键道具+场景物件继承。
3. 角色绑定行取核心角色前 3；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填道具+功能+光色 | 留空→继承场景物件（可能全是现实物），未来感无从建立 |
| 核心数据包 | Core 输出 JSON 包 | 不接→角色绑定行消失、无清单继承 |
| 视觉风格 | 写实/3D CG | 进提示词行；"🎲 随机"→系统随机 8 选 1 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；发光界面跨镜色彩漂移率高 |

## 已知坑

- "界面光色统一世界观"需要与科幻场景卡的光色一致——两卡各自建，节点不做跨卡色值对齐。
- 功能可读性依赖外形隐喻（"圆润=医疗"），描述里不写明用途时生成结果功能感随机。
