## 意图

要一个"不是纯恶人"的对抗角色时选它。与其他角色模式的本质差别：性格留空时不走通用性格池，而走反派专属 5 条池（"礼貌周到, 狠在不动声色"式动机自洽描述），叙事定位锁定"对抗轴心"。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["反派角色"]`（"对抗轴心 — 主角价值观的镜像与考验, 动机自洽不脸谱"）。
2. 性格缺省特判：从反派专属池（礼貌周到狠在不动声色 / 信念坚定站错位置 / 控制欲极强恐惧失控 / 魅力型操纵者 / 旧伤驱动偏执）种子选 1——11 个角色模式中唯一的专属性格池。
3. 姓名继承特判：默认名"主角"且核心场景解析出 ≥2 个角色时取末位当反派名；仅 1 人时取首位。
4. 道具绑定与三视图锚定与单角色分支一致（正面/侧面/背面/表情变体 IP-Adapter 提示词）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色性格 | 留空走反派专属池 | 填值→原样使用，专属池被跳过；写"邪恶疯狂"式脸谱词不会被清洗 |
| 角色名 | 主角 | 默认名 + 核心场景 ≥2 角色→静默改为解析末位角色名；显式改名则不继承 |
| 核心数据包 | Core 输出 JSON 包 | 非法 JSON→{}：姓名继承/道具绑定/情绪基调全部失效，退回纯手填卡 |
| 角色外貌 | "短发, 瘦削..."（默认） | 留空→走 _LOOK_TRAITS 种子补全，与正派共用外貌池（无反派专属外貌池） |

## 已知坑

- 末位继承仅在 len(core_chars)>=2 时生效；场景只解析出 1 人时反派拿首位——想把某人设成反派应显式填角色名。
- 反派专属池只在性格为空时触发；默认值槽里若残留上一次的通用性格文案会原样输出。
- tests/test_all_modes.py 对本模式断言执行非空且参与唯一输出 hash 统计。
