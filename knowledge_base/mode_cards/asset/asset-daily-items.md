## 意图

给背景生活物（牙刷/茶缸/拖鞋）建卡、用物件交代人物习惯时选它。指令三条：用品即人物习惯的化石、品牌/年代可辨识或彻底素体、使用痕迹真实。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["日常用品"]` 三条（习惯化石/品牌素体二选一/痕迹真实）。
2. 清单装配走服化道分支继承链：用品清单写进服化道描述；留空→_关键道具+场景物件继承（厨房场景继承灶台/碗柜类物件正合适）。
3. 角色绑定行取核心角色前 3；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填用品清单与痕迹 | 留空→继承场景物件；两头空→"未指定"+占位提示词 |
| 核心数据包 | Core 输出 JSON 包 | 不接→角色绑定行消失、无清单继承 |
| 视觉风格 | 写实 | 进提示词行；"🎲 随机"→系统随机 8 选 1 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；小物件形状相似度高，跨镜易换物 |

## 已知坑

- "品牌可辨识"与生成模型的 IP 规避倾向冲突——真品牌名可能被下游模型改写或拒绝，素体化是稳妥路径。
- 本模式与"道具设计"分支相同，差异仅指令块；叙事级道具走道具设计，氛围级用品走本模式。
