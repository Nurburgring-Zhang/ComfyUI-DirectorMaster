## 意图

闪回/回忆段落建卡时选它。指令三条定义记忆质感：色调抽离（过曝或褪色）、细节选择性清晰（只有情绪焦点清楚）、声音先于画面出现——与梦境的"变形"不同，记忆的规则是"选择性"。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["记忆场景"]` 三条（色调抽离/选择性清晰/声音先行）。
2. 环境描述留空→场景描述→parse_scene 地点词→空串；记忆场景通常复用现实地点，描述行写"同一厨房但过曝"式对照最有效。
3. 场景内道具行核心物件前 4——记忆焦点物件（旧信/照片）建议写进 _关键道具。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填记忆对照差异 | 留空且无核心包→环境描述行空串，与现时场景无差异可写 |
| 情绪基调 | 经核心包继承 | 不接核心包→情绪行为空，"按情绪定光影"锚空转 |
| 核心数据包 | Core 输出 JSON 包 | 不接→道具行"无"、导演固定"王家卫"（主观记忆流适配度高的导演反而歪打正着） |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；记忆与现实的色调差异需靠调色执行 |

## 已知坑

- "声音先于画面出现"是剪辑层指令，本卡只输出文本，执行在分镜/剪辑侧。
- 记忆场景与现实场景常共用同一地点——若两张卡各自建（现实用室内环境、记忆用本模式），环境描述需人工保持同源，节点不做跨卡一致性校验。
