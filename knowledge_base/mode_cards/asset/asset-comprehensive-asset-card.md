## 意图

项目开拍前想一张"总资产策略卡"时选它。设计指令描述三库联动策略：角色/环境/道具三库联动、母版资产锁定后批量派生、跨镜头一致性优先。

## 核心手法

1. 走服化道分支装配：清单读服化道描述；留空→_关键道具+场景物件合并继承；角色绑定行取核心角色前 3。
2. 设计指令块输出 `_PROP_DESIGN["综合资产卡"]` 三条（三库联动/母版派生/一致性优先）。
3. 与单库模式的差别在策略层：母版→派生链的资产组织方式，配合参考图槽（角色三视图 3 槽 + 环境母版 + 道具母版）一起喂。
4. 一致性策略统计道具母版参考图数；生成提示词行按视觉风格+材质纹理+情绪组装。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填三库核心资产清单 | 留空→继承 _关键道具+物件，总卡清单偏科道具库 |
| 参考图_角色正面/侧面/背面 | LoadImage IMAGE | 三视图接齐才支撑"母版锁定后派生"；缺槽→对应视图不进参考库 |
| 核心数据包 | Core 输出 JSON 包 | 不接→无角色绑定、无场景物件继承，三库联动只剩指令文本 |
| 参考图_环境母版/道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0，派生链无根 |

## 已知坑

- 本模式走 else 服化道分支，输出卡头是"服化道卡"——没有独立的三库渲染器；"三库联动"只存在于设计指令文本与用户描述里，角色/环境仍需另开对应模式建卡。
- 参考图 JSON（第二输出）所有模式都会生成，本模式无附加 JSON 结构。
