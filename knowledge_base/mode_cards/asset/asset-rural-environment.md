## 意图

村庄/农田/小镇建卡时选它。与其他环境模式的差别：指令三条为"土路/植被季节性真实 / 炊烟与狗吠的空间感 / 光线无遮挡, 阴影硬朗"——乡村光的标志是硬阴影。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["乡村环境"]` 三条（季节真实/炊烟狗吠空间感/硬朗阴影）。
2. 环境描述留空→场景描述→parse_scene 地点词（"村/镇/小院/渡口"命中）→空串。
3. 场景内道具行核心物件前 4（农具/家禽等）；环境锚定按导演定主色、按情绪定光影。
4. 一致性策略统计环境母版数，跨镜头空间/光影/色调锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填村落布局 | 留空且无核心包→环境描述行空串 |
| 环境类型 | 室外 | "🎲 随机"→系统随机 5 选 1，类型与指令无联动校验 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"村"命中"村庄"、"镇"命中"小镇"；不接→道具行"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；季节植被全靠文本锚，跨季节镜头易穿帮 |

## 已知坑

- parse_scene 地点词表"村/村镇/镇"分别映射村庄/小镇，场景里"村镇"两字按最长匹配取"小镇"——想保村庄锚需避免"镇"字混入。
- 炊烟/狗吠是听觉与氛围指令，输出为文本设计指令，下游视频模型不会自动执行。
