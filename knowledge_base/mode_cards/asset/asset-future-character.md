## 意图

近未来/赛博背景建角色卡时选它。与其他角色模式的差别：服装留空走 `_ERA_WARD["未来角色"]`（"无缝剪裁, 哑光功能面料, 隐藏式接口"），叙事定位锁定"科技外饰保留人性内核, 装备服务于性格"。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["未来角色"]`。
2. 时代衣冠补全：服装留空→_ERA_WARD 命中，输出无缝剪裁/哑光面料/隐藏式接口描述，防止未来感退化成"贴 LED 的现代装"。
3. 姓名继承首位；性格/外貌走通用种子池（未来无专属性格池）。
4. 三视图锚定 + 表情变体；道具绑定核心物件首项。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色服装 | 留空走 _ERA_WARD["未来角色"] | 填值原样使用；填"宽袖长袍"式古风文案不会被纠偏 |
| 视觉风格 | 写实 | "🎲 随机"→系统随机 8 选 1，可能抽到水彩/油画削弱未来质感 |
| 角色性格 | 留空走通用池 | 无未来专属性格池；"装备服务性格"需用户在性格/服装槽自写关联 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"太空站/飞船/空间站"命中 parse_scene 地点表，出场场景行获得锚 |

## 已知坑

- 与科幻角色共享通用池但服装池不同（无缝剪裁 vs 轻量化磨损）——两个模式混用会产出两种未来质感，跨镜头需统一模式。
- 补全种子含模式名：同一人物在建卡模式间切换时性格补全会变。
