## 意图

设计角色妆面/发型/特效妆（伤效/老年妆）时选它。指令三条为妆造专属：妆面服务于灯光（高清镜头吃妆）、发型有物理逻辑（风向/湿度）、伤痕/老化妆效可触。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["化妆造型"]` 三条（灯光适配/发型物理逻辑/特效妆可触）。
2. 清单装配走服化道分支继承链：妆面方案写进服化道描述；留空→_关键道具+场景物件合并占位。
3. 角色绑定行取核心角色前 3——妆与脸绑定；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计参考图数——妆效参考接"参考图_角色正面"槽（脸部锁定）比道具母版更贴。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填妆面/发型/伤效方案 | 留空→清单被场景物件占位，妆造卡内容失焦 |
| 核心数据包 | Core 输出 JSON 包 | 不接→角色绑定行消失，妆造方案无人脸可挂 |
| 视觉风格 | 写实 | "日漫/美漫"时特效妆指令与画风规则需用户自行调和 |
| 参考图_角色正面 | IMAGE 或 STRING 路径 | 不接→正面参考计数 0；妆效跨镜一致性最依赖面部锁定 |

## 已知坑

- 节点无妆造专属参考槽，卡面一致性策略行固定写"道具母版"计数——接在角色正面槽的图不计入该行数字。
- "高清镜头吃妆"是拍摄执行指令，输出为文本，不会改写下游生成参数。
