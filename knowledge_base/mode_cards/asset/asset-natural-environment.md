## 意图

山林/河湖/荒野建卡时选它。与"室外环境"的差别：指令三条聚焦自然专属——风声水声作情绪底色、植物近草/中灌/远林三层、天气变化推动情节。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["自然环境"]` 三条（声音底色/植物三层/天气推情节）。
2. 环境描述留空→场景描述→parse_scene 地点词（"森林/沙漠/雪山/海边/山中"命中）→空串。
3. 场景内道具行核心物件前 4；环境锚定块按导演定主色、按情绪定光影。
4. 一致性策略统计环境母版数，输出跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填地貌与季节 | 留空且无核心包→环境描述行空串 |
| 环境类型 | 室外 | 类型槽仅作显示行，与指令块无联动校验 |
| 核心数据包 | Core 输出 JSON 包 | 场景词"森林/沙漠"命中地点表；"河/湖/江/海"分别映射河边/湖边/江边/海边；不接→道具行"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0，植物层次与光线纯靠文本锚 |

## 已知坑

- parse_scene 单字地点词"山/海/河"匹配面宽，描述含"上海"时由城市词修复规则兜住（V16.1），但自造词（"林海"）可能误命中"海"→海边。
- 风声水声指令输出为文本，声音执行在 DirectorMasterSound 侧，本卡不产出声音参数。
