## 意图

一次规划整部戏的服装/化妆/道具清单时选它。与 10 个细分模式的差别：总卡视角——每件道具承载一个情感/叙事功能、材质磨损具体到可拍、服装色彩与场景主色形成关系。

## 核心手法

1. 服化道卡装配：读服化道描述清单；描述留空→继承核心包 _关键道具 + parse_scene 物件前 4 个（去重合并）。
2. 设计指令块输出 `_PROP_DESIGN["服化道设定"]` 三条（情感功能绑定/材质年代磨损可拍/服装色彩与场景主色成关系）。
3. 角色绑定行：核心场景解析角色前 3 个顿号连接，把道具与人关联。
4. 一致性策略统计道具母版参考图数，输出"跨镜头外观/材质锁定"；生成提示词行按视觉风格+材质纹理+情绪组装。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | "旧信(泛黄), 凤梨罐头(过期), 钢笔(没墨水), 收音机"（默认） | 留空→按 _关键道具+场景物件合并继承；两头都空→清单行输出"未指定"，提示词行退回占位词"核心道具" |
| 核心数据包 | Core 输出 JSON 包 | 不接→无角色绑定行、无清单继承，只剩手填描述 |
| 视觉风格 | 写实 | 进生成提示词行；"🎲 随机"→系统随机 8 选 1 非确定 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；材质纹理跨镜一致性全靠文本 |

## 已知坑

- 清单继承的去重判断是子串包含（`o not in key_props_core`），物件名与关键道具部分重叠时可能重复出现。
- 默认描述含"凤梨罐头(过期)"——不改直接用会进所有下游提示词，示例文案不是占位符而是真实输出内容。
