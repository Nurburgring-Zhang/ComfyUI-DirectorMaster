## 意图

给冷兵器/热武器/奇幻武器建卡时选它。指令三条是武器专属表演语言：重量感通过演员身体表现、磨损/包浆暗示使用历史、机关结构逻辑自洽。

## 核心手法

1. 设计指令块输出 `_PROP_DESIGN["武器设计"]` 三条（身体重量感/包浆历史/机关自洽）。
2. 清单装配走服化道分支继承链：武器名与特征写进服化道描述；留空→_关键道具+场景物件继承。
3. 角色绑定行取核心角色前 3——武器与持有者绑定；生成提示词行按视觉风格+材质纹理+情绪组装。
4. 一致性策略统计道具母版参考图数，跨镜头外观/材质锁定。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 服化道描述 | 填武器形制与材质 | 留空→清单继承场景物件（可能无武器），武器卡内容失焦 |
| 核心数据包 | Core 输出 JSON 包 | 武器写进 _关键道具 可同时进角色卡道具绑定行；不接→继承断 |
| 视觉风格 | 写实 | "3D CG"与"物理重量感"指令的风格张力需用户调和 |
| 参考图_道具母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；武器轮廓对称性靠文本锚易漂移 |

## 已知坑

- "重量感通过演员身体表现"落在表演层，输出为文本指令；武器持握姿态需在分镜侧落实。
- 机关结构（可展开/变形）若只写"可变形"三字，跨镜生成易崩——描述里写清机件构成。
