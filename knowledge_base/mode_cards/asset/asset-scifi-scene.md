## 意图

未来城市/基地/舰桥建卡时选它。与"太空环境"的差别：太空管零重力物理，本模式管科技物质感——科技有使用痕迹不崭新、界面信息可读、空间逻辑服务于世界观。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["科幻场景"]` 三条（使用痕迹/界面可读/空间服务世界观）。
2. 环境描述留空→场景描述→parse_scene 地点词（"太空站/飞船"等科幻词命中）→空串。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调光影。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填科技空间构成 | 留空且无核心包→环境描述行空串 |
| 环境类型 | 室内/室外按场景 | 类型槽仅显示行；"🎲 随机"→系统随机 5 选 1 |
| 核心数据包 | Core 输出 JSON 包 | 不接→道具行"无"；界面/全息类物件写进 _关键道具 可进道具行 |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；全息界面发光稳定性差 |

## 已知坑

- "界面信息可读"要求界面内容具体，卡面只给指令不给界面文案——界面文字需进环境描述或下游分镜。
- 与"未来道具"模式分工：环境级科技（舰桥/全息墙）在本模式，手持级科技（终端/义肢）走未来道具卡。
