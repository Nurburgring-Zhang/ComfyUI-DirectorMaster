## 意图

超自然/神话背景建角色卡时选它。与其他角色模式的差别：服装留空走 `_ERA_WARD["奇幻角色"]`（"手工感服饰, 符号纹样, 材质混搭"），叙事定位强调"视觉符号强, 能力有代价"。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["奇幻角色"]`。
2. 时代衣冠补全：服装留空→_ERA_WARD 命中，输出手工感/符号纹样/材质混搭描述——奇幻服饰的辨识度锚定在纹样而非剪裁。
3. 姓名继承首位；性格/外貌走通用种子池。
4. 三视图锚定的表情行含中性 + 微笑/凝重/惊讶 3 变体，奇幻角色常需额外能力表情（施法/异变），当前需用户在性格槽自写。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色服装 | 留空走 _ERA_WARD["奇幻角色"] | 填值原样使用；留空→手工感服饰/符号纹样/材质混搭 |
| 角色外貌 | 留空走 _LOOK_TRAITS | 通用池是写实系外貌（老茧/青黑），超自然特征（瞳色/纹身）需用户自写 |
| 核心数据包 | Core 输出 JSON 包 | 非法 JSON→{}：导演回退"王家卫"、道具绑定失效 |
| 参考图_角色正面 | IMAGE 或 STRING 路径 | 不接→一致性策略计 0 张；符号纹样无参考图极易跨镜头漂移 |

## 已知坑

- 外貌补全池为写实系细节池，奇幻角色的超自然外貌特征完全依赖手填——留空可能产出与奇幻定位违和的普通外貌。
- _ERA_WARD 奇幻键与古风键风格相近（都是手工/纹样系），建卡时注意模式选对，否则卡头叙事定位与下游消费对不上。
