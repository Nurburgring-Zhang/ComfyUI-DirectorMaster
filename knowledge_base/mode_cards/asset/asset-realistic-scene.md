## 意图

纪实感/生活流场景建卡时选它。指令三条确立写实美学：自然光优先不打修饰光、环境音完整保留、允许画面"不完美"——与奇幻/科幻系的"规则化光源"路线相反。

## 核心手法

1. 设计指令块输出 `_ENV_DESIGN["现实场景(写实)"]` 三条（自然光/环境音/允许不完美）。
2. 环境描述留空→场景描述→parse_scene 地点词→空串；写实场景描述越具体（"楼道声控灯"）锚越稳。
3. 场景内道具行核心物件前 4；环境锚定按导演/情绪定色调光影——写实导演（贾樟柯系）配本模式更贴。
4. 一致性策略统计环境母版数，跨镜头锁定行。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 环境描述 | 自填真实空间 | 留空且无核心包→环境描述行空串 |
| 视觉风格 | 写实（默认即对齐） | 选"日漫/赛璐璐"与写实指令冲突，输出不做拦截 |
| 核心数据包 | Core 输出 JSON 包 | 场景词命中地点表（"便利店/地铁/菜市场"）；不接→道具行"无" |
| 参考图_环境母版 | IMAGE 或 STRING 路径 | 不接→母版计数 0；实景参照是写实一致性的最强锚 |

## 已知坑

- 模式名带半角括号"现实场景(写实)"，下拉名含括号——manifest 与卡 name 逐字含括号，检索时别写成"现实场景"。
- "允许画面'不完美'"指令与部分视频模型的画质增强默认行为相反，执行侧需手动抑制美化。
