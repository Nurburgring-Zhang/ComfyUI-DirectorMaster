## 意图

当代都市/生活流故事建角色卡时选它。与"角色设定"的差别：服装留空走 `_ERA_WARD["现代角色"]`（"当代成衣, 有生活褶皱"），叙事定位强调"生活质感优先, 细节真实可触"。

## 核心手法

1. 叙事定位取 `_CHAR_ROLE_HINT["现代角色"]`。
2. 时代衣冠补全：服装留空→_ERA_WARD 命中，输出"当代成衣, 有生活褶皱"——相比通用池的单件磨损描述（袖口缝补/鞋变形），更强调整身时代感与穿着状态。
3. 姓名继承首位（默认名"主角"且核心场景有人物时），性格/外貌走通用种子池。
4. 三视图锚定 + 表情变体；道具绑定核心物件首项（现代题材常见手机/钥匙等）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 角色服装 | 留空走 _ERA_WARD["现代角色"] | 填值原样使用；留空→"当代成衣, 有生活褶皱" |
| 角色外貌 | "短发, 瘦削..."（默认） | 留空→_LOOK_TRAITS 种子补全（晒痕/青黑/指甲细节） |
| 核心数据包 | Core 输出 JSON 包 | 场景词"便利店/写字楼/地铁"命中 parse_scene 地点表，出场场景行获得具体锚 |
| 参考图_角色正面 | IMAGE 或 STRING 路径 | 不接→一致性策略计 0 张；现代服化全靠文本锚易漂移 |

## 已知坑

- 现代角色与古风/科幻模式共用通用性格/外貌池，只换服装池——人设的时代感差异全部压在服装一行。
- 补全种子含项目名：改项目名即改变补全外貌，跨项目复用人设需手填。
