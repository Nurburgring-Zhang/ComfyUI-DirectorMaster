## 意图

立室内空间锚点时选它。与环境设定的差别收敛为 `_ENV_DESIGN` 三条专属指令（窗户位置决定光路 / 家具磨损程度暗示居住年限 / 墙面物件交代人物背景）；分支代码、继承逻辑、卡结构完全共用。

## 核心手法

- 进入 `elif mode in _ENV_MODES:` 分支，产出环境卡落「环境圣经」路；本模式输出六路中角色圣经/服化道圣经为空串。
- 设计指令块注入 `_ENV_DESIGN["室内环境"]` 三条：① 窗户位置决定光路 ② 家具磨损程度暗示居住年限 ③ 墙面物件交代人物背景。
- 环境描述清空时继承核心场景文本；场景内道具行取 parse_scene 物件前 4 个（顿号连接）或 _关键道具 首段，全无写「无」。
- 环境锚定块按导演定主色调、按情绪定光影、按场景描述定道具位置；生成提示词拼「室内场景, 描述, 风格, 导演, 情绪」（前缀来自环境类型下拉）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 节点模式 | 室内环境 | 非法值回退 角色设定，产出角色卡 |
| 环境描述 | 厨房8平米, 灶台+砧板+碗柜+餐桌+窗 | 默认值不清理就原样进卡；清空后继承核心场景文本 |
| 环境类型 | 室内 | 本模式语义应选室内；选其他值不改分支，只把提示词前缀换成「太空场景」等 |
| 视觉风格 | 写实 | 逐字进环境锚定与生成提示词；🎲 随机时输出不可复现 |

## 已知坑

- 环境类型下拉与子模式不联动：提示词前缀由下拉决定，选「太空」会产出「太空场景, 厨房8平米…」式混搭。
- 默认环境描述是厨房示例文本，与本模式组合恰好自洽，但换场景时必须清理。
- 三视图锚定路输出占位句「(非角色模式 — …)」；MIP 资产卡仍是角色向内容（主 IP 取角色名），环境模式无需消费它。
- tests/test_all_modes.py 断言本模式执行非空（六路拼接）。

## 节点映射

- 实现文件：aggregator/characters_master.py :: DirectorMasterCharacters.build()（ASSET_MODES 委托 + env 路由）
- 分支/函数：aggregator/asset_master.py :: DirectorMasterAsset.build() `elif mode in _ENV_MODES:` 分支；设计指令 `_ENV_DESIGN["室内环境"]`
- 数据来源：aggregator/scene_engine.parse_scene（物件/地点继承）
