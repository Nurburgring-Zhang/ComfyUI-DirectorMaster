## 意图

立对抗轴心时选它。相对角色设定有三个专属行为：专用反派性格池、「动机自洽不脸谱」定位文案、角色名留默认时自动继承场景解析出的末位人物（普通模式取首位）。

## 核心手法

- 走 `_CHARACTER_MODES` 单角色分支，叙事定位注入 `_CHAR_ROLE_HINT["反派角色"]`＝「对抗轴心 — 主角价值观的镜像与考验, 动机自洽不脸谱」。
- 性格字段清空时走 5 条专用池（礼貌周到狠在不动声色 / 信念坚定只是站错位置 / 控制欲极强恐惧失控 / 魅力型操纵者从不提高嗓门 / 旧伤驱动的偏执），按场景+模式种子确定命中，probe 实证命中「控制欲极强, 恐惧失控」。
- 角色名继承用三元规则：`core_chars[-1] if (mode == "反派角色" and len(core_chars) >= 2) else core_chars[0]`——多人物场景把末位给反派，避免反派与主角同名。
- 服装清空无时代池，走 _WARD_TRAITS 通用池；卡结构与其余单角色模式一致（三视图锚定+一致性策略+生成提示词+道具绑定）。

## 参数表

| 参数 | 典型值 | 越界后果 |
|---|---|---|
| 节点模式 | 反派角色 | 非法值回退 角色设定，专用性格池与末位继承同时失效 |
| 角色名 | 主角 | 场景解析 ≥2 人时自动换成末位人物；只有 1 人时与普通模式相同取首位 |
| 角色性格 | （建议清空让池生效） | 留默认值则默认文本直接进卡，5 条专用池完全不触发 |
| 核心数据包 | 含 _场景描述 的 JSON 包 | 场景为空 → 无人物可继承、无道具绑定，反派名停在「主角」 |

## 已知坑

- 末位继承要求 len(core_chars)≥2：单人物场景的反派名与主角模式结果相同，别指望自动区分。
- 专用池仅 5 条：同一场景反复生成只在 5 条间按种子轮换，想要更多反派性格变体需手填。
- 场景解析可能给出「主角/副线」占位名（parse_scene 词表式提取的已知局限），反派姓名行会照抄占位名。
- 道具绑定仍只取第一物件（_关键道具 首段 "(" 前文本），反派的「标志物」要第二件得手写进外貌/服装字段。

## 节点映射

- 实现文件：aggregator/characters_master.py :: DirectorMasterCharacters.build()（ASSET_MODES 委托段）
- 分支/函数：aggregator/asset_master.py :: DirectorMasterAsset.build() 单角色分支内反派子支——`if mode == "反派角色":` 性格池替换 + 角色名三元继承
- 数据来源：反派性格专用池与 _CHAR_ROLE_HINT（节点内置）；aggregator/scene_engine.parse_scene
