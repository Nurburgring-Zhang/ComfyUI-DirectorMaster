# 双版本对比裁决报告：GitHub 版（已强化至 V16.3.0）vs 附件版（自称 V16.6-AIGC）

> 审计方式：双版本全部真实运行（doctor + 各自全部测试套件）+ 文件级/特征级 diff + 逐行源码审查。
> 附件版内部事实：压缩包名 V16.6-AIGC，内部目录名 `V16.0.1-MERGED`，`__version__="16.6.0"`，
> 文件头注释"V16.0-MERGED / V16.1-AIGC"——**四处版本口径互相矛盾**。

## 一、裁决结论

**GitHub 版（本仓，已强化至 V16.3.0）显著更完善，作为继续优化的基座。**
附件版仅作为"创意参考源"吸收其真实增量（复杂叙事拓扑引擎 + 强化测试维度），不作为基座。

## 三、附件版自身问题清单（实测证据）

1. 自带 audit 17 FAIL 未披露照常发布（违反项目零虚假红线）。
2. 删除测试套件而非修复（llm_resilience/load_isolation/aigc_random_full 消失）。
3. schema 英文化断裂自带审计与工作流兼容。
4. 版本口径四处矛盾。

## 四、吸收计划（R7，在 GitHub 基座上增量实施）

仅吸收两件真实增值，全部**增量式**（不动既有 schema/契约）：
1. `aggregator/plot_topology.py`：按 GitHub 的场景/分镜数据结构重写拓扑引擎
   （波浪数/反转点位置/层层推进/复杂结构检测/套层框架带），确定性 md5 种子驱动，
   接入 Cinematic JSON 新增 `叙事拓扑` 元数据块（纯增量键）。
2. `tests/test_random_full_v16.py`：移植附件版 614 断言中的高价值维度
   （时长归一/多样性/张力跨度/相邻焦点去重/复杂结构端到端），适配 GitHub 的中文 schema，全绿为准。
