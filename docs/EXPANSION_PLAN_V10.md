# 扩充计划 V10 (Expand to World-Class Director-Level Output)

## 目标
确保知识库所有数据可被真实调用,产出世界顶级导演级输出:
剧本/分镜/角色设计/环境设计/故事情节设计/叙事推进/大师级运镜转场/
顶级导演剪辑技巧/故事线安排/互动交互/画面感氛围感 等全维度。
零虚假,零容忍。

## 阶段划分

### Phase 1: 富信息作品库扩充 (26→45+)
真实深度10维度作品,覆盖电影/电视剧/短剧/短视频。
新增: 电影(阿甘/辛德勒/海上钢琴师/三傻/楚门/无间道/指环王/千与千寻等)
电视剧(纸牌屋/黑镜/西部世界/隐秘的角落)
短剧(家里家外/夕阳之恋/十八岁太奶奶/野火燎原)
短视频(黑脸V/房琪/陈翔六点半)

### Phase 2: 维度输出模块 (用户列的每个输出维度都有callable模块)
- character_design.py: 角色设计(原型/弧光/外貌/服装/动机/关系网)
- environment_design.py: 环境设计(空间叙事/色彩方案/道具符号/光照/质感)
- story_design.py: 故事情节设计(结构骨架/伏笔地图/角色弧光/主题/logline)
- interaction_design.py: 互动交互(短视频互动钩子/选择/评论/分享转化)
- atmosphere_design.py: 画面氛围感(光影/色彩/质感/声音/留白)
(剧本/分镜/叙事推进/运镜转场/剪辑技巧/故事线 已被现有模块覆盖)

### Phase 3: 接线所有输出模块到引擎
引擎build_system_prompt按输出维度调用对应模块,每维度真实callable。
节点新增"输出侧重"可选输入(分镜/角色/环境/故事/氛围/互动)。

### Phase 4: 深度测试审核
扩展test_full_audit: 验证每个输出维度的数据可调用且产出真实指导。
模拟真实生成路径(空API早退+真实prompt注入验证)。

### Phase 5: 打包 + GitHub同步
打包V10, git push到origin (Nurburgring-Zhang/ComfyUI-PromptLibraryNode)。

## 每阶段自我质疑
- 数据是否真实专家级(非占位)?
- 是否真正callable(注入路径打通,非死数据)?
- failure_modes是否技法特定(非泛泛)?
- 测试是否覆盖(非仅编译通过)?
