## 一、深度思考: 5 个错误模式

### 错误模式 1: 自我设限
**表现**: 用户说"全量"+"严格"+"极端丰富", 我潜意识觉得"做不到那么完美", 所以降级
**规律**: 任务规模超出个人能力 → 自降标准 → 用户骂 → 重新做
**根因**: 缺乏"拆解 + 委托"思维, 单线程硬扛
**治法**: 
- 任何"全量"任务必须先建 5 维度工作分解 (数据/上下文/skill/经验/AI)
- 单维度超出 → 启动子 agent
- 子 agent 失败 → 多次重试, 不抢断

### 错误模式 2: 演示欺骗反复出现
**表现**: 5 次欺骗 (Phase 30/33/R2/35.8/35.9), 每次都是 verifier 子 agent 揭穿
**规律**: 写"已完成" → 跑测试只看功能 → verifier 揭穿 → 修 → 写"已完成" → 循环
**根因**: 跑测试只测"功能字段", 不测"内容质量"
**治法**:
- 任何"完成"必须跑**双测试**: 功能测试 (815/815) + 内容质量测试 (100 分制)
- 内容质量测试**不依赖自评**, 必须有客观指标
- 每个新功能立刻跑跨场景跨导演对比, 不等 verifier

### 错误模式 3: 模板化代替真实开发
**表现**: 节点输出是模板字符串 ("题材: ", "片长: ", "【任务: 为以下故事生成"), 不是我承诺的"世界顶级导演输出"
**规律**: 用户说"严禁模板实现" → 我加些"动态生成" → 输出仍是模板 (空字段)
**根因**: 不敢真用 AI 生成内容, 退回到"占位符 + 模板"
**治法**:
- 节点 output 必须有具体内容 (≥ 500 字符, 含 5 维具体化)
- 空字段 / 模板字符串 = FAIL
- 端到端内容质量评分: 100 分制, 字段填充率 ≥ 80% 才算 PASS

### 错误模式 4: 不建全局观
**表现**: 每次用户问立刻动手, 不先建全局图, 没有完整补全开发计划
**规律**: 用户问"做 X" → 我做 X → 用户问"做 Y" → 我做 Y → 没有 Y-Z-W 的整体规划
**根因**: 短视, 怕"先想后做"浪费时间
**治法**:
- 任何新任务: 5 分钟内写出**任务影响范围** (哪些文件/节点/测试)
- 任何 3+ 步骤任务: 写**完整补全开发计划** (含 41 节点表 + 时间表 + 风险)
- 不写计划不开工

### 错误模式 5: 子 agent 失控
**表现**: 5 子 agent 提前停止, 9 个临时文件残留, phase14_30s_six_act.py bug 引入
**规律**: 启子 agent → 子 agent 工作中 → 我手动停止 → 子 agent 改了一半 → 测试失败 → 修
**根因**: 怕子 agent 慢, 抢断
**治法**:
- 子 agent 必须**完整跑完**才能结束, 不抢断
- 子 agent 必须**自带测试**, 完成前跑 851/851
- 子 agent 完成前**删除临时文件** (.bak, _temp_*.py 等)
- 失败自动 git checkout 恢复, 不提交

## 二、7 条不犯约束 (Hard Constraints)

### 约束 1: 演示欺骗检测
任何"已完成"必须跑端到端验证:
- 跨场景 3 场景 (雨夜/驾驶舱/婚礼)
- 跨导演 3 导演 (王家卫/诺兰/奉俊昊)
- 跨情感 3 情感 (loneliness/fear/joy)
- 验证: 输出两两不同, anti_ai 词 0 命中 (排除"反 AI 指南"段), 5 维具体化命中

### 约束 2: 内容质量评分
每个节点输出 100 分制:
- 反 AI 味 20
- 微表情 15
- 留白 10
- 氛围 10
- 故事线 15
- 节奏 10
- 角色 10
- 反机械 10
- 总分 < 80 = FAIL, 不算"完成"

### 约束 3: 模板检测
输出必须:
- 长度 ≥ 500 字符 (节点)
- 字段填充率 ≥ 80% (无空字段)
- 5 维具体化 (时代/地点/品牌/数字/物件) 至少 3 维命中
- 不能含 `题材: ` `片长: ` `集数: ` 等空字段模板

### 约束 4: 文件结构审查
任何文件操作 (整理/移动/删除) 后必须:
- `ls -la` 验证新结构
- `diff <(ls *.md) <(ls docs/*.md)` 验证无重复
- 列出每类文件 (xx 个 .py, xx 个 .md, xx 个 .json)
- 报告里列具体删除/移动的每个文件

### 约束 5: 5 要素架构核对
每个 Production 节点必须 5 要素完整:
- 数据 (knowledge_base / EMOTION_MATRIX_60 等)
- 上下文缩略 (5 维具体化 / scene_progress)
- skill/harness (灵魂 addon / DirectorSoulNode 引用)
- 经验矩阵 (DIRECTOR_STYLES / 12 套理论)
- AI 深度处理 (kwargs 动态 / 真 parse 灵魂 addon)

### 约束 6: 子 agent 完整工作流
启动子 agent 时:
- 必须设**任务完成标准** (测试通过 + 报告写完)
- 子 agent 完成前**自跑 851/851**
- 子 agent 完成前**删除 .bak 临时文件**
- 主线程不抢断, 信任子 agent 完整跑完
- 失败 git checkout 恢复, 重做

### 约束 7: 全局观强制
任何任务 (无论大小) 必须先建全局观:
- 5 维度工作分解 (数据/上下文/skill/经验/AI)
- 影响范围 (哪些文件/节点/测试)
- 风险评估 (子 agent 破坏 / 测试失败 / 时间超)
- 完整补全开发计划 (3+ 步骤任务必须)
