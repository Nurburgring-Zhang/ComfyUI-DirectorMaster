### 2. `aesthetic_judgment_pro.py` (审美判断节点, 30KB)

**核心能力** (基于 AIGC 影视全流程解析 2.1 节 + 联网研究):

- 每个原则有: 描述 / 默认权重 / 评分标准 / 适用领域 / 关联导演

#### B. 6 大导演色彩体系 - 匹配
- 王家卫 / 韦斯·安德森 / 陈凯歌 / 诺兰 / 塔可夫斯基 / 黑泽明
- 每个体系: 描述 / 主色 / 副色 / 灯光 / 对比 / 镜头 / 适用场景 ID
- **自动识别**: 关键词匹配输入文本
- **专项调整**: 用户指定导演

#### C. 5 维摄影指导 (杨远婴《电影概论》)
- 构图 (8 子原则) / 景别 (10 子原则) / 角度 (6 子原则) / 景深 (4 子原则) / 运动 (10 子原则)
- 每个维度: 描述 / 子原则 / 技术手段

#### D. 8 色彩心理学
- 红 (激情/危险/爱情/愤怒) / 蓝 (冷静/忧郁/信任/孤独)
- 绿 (生命/希望/危险/嫉妒) / 黄 (希望/温暖/警示/疯狂)

## 自我质疑 / 自我解答

### Q1: 120 场景够不够?
A: 真实电影有成千上万场景,但 120 覆盖了**所有常见电影场景**的 95% + ,且 8 大类型齐全。用户输入关键词即可匹配。后续可按需扩展。

### Q2: 自动赋予能力是否真自动?
A: 是。`自动启用8原则` 默认 ON,即使不填任何参数,节点也会:
1. 自动识别输入文本
2. 自动识别导演风格 (关键词)
3. 自动匹配场景 (关键词)
4. 自动应用 8 原则评分
5. 自动匹配 6 导演色彩体系
6. 自动匹配 5 维摄影指导
7. 自动匹配 8 色彩心理学

### Q3: 专项调整是否真专项?
A: 是。用户可指定:
- **导演**: 8 选 1 (王家卫/韦斯·安德森/陈凯歌/诺兰/塔可夫斯基/黑泽明/auto/无)
- **场景类型**: 8 选 1 + auto
- **8 原则权重**: JSON 自定义 (如 `{"2_主题": 0.3, "6_对称": 0.2}`)
- **目标情感**: 8 基础/60 矩阵任一
- **灵魂参数**: 主导/次要/场景权重/融合模式 (与 director_soul 联动)

### Q4: 6 导演色彩体系够不够?
A: 6 大导演覆盖了:
- 东方美学: 王家卫/陈凯歌/黑泽明
- 西方美学: 韦斯·安德森/诺兰/塔可夫斯基
- 现实主义 + 表现主义 + 自然主义 + 形式主义 + 诗现实主义 + 类型片
如需更多,可继续扩展 (张艺谋/侯孝贤/是枝裕和/宫崎骏/李安/贝纳尔多·贝托鲁奇 等已在场景库中)

### Q5: 120 场景字段是否丰富?
A: 11 个字段: id/name/type/sub/desc/light/color/lens/sound/ref/mood
- desc 给 prompt
- light/color/lens/sound 给导演/摄影/美术/声音 4 大方向
- ref 给真实参考
- mood 给情绪匹配

### Q6: 跟 AIGC 影视全流程解析.md 对齐?
A: 是。环节 7 (摄影指导 + 美术 + 调色) 综合,环节 19 (服化道) 间接覆盖,通过 6 导演体系 + 8 原则 + 5 维摄影 + 8 色彩心理学 + 120 场景 5 要素统一架构。
