## 🚀 快速开始

### 安装
将整个目录复制到 ComfyUI/custom_nodes/ComfyUI-PromptLibraryNode/

### 使用
在 ComfyUI 节点菜单中, 找到 "PromptLibrary" 分类, 选择需要的节点。

### 核心工作流
1. **DirectorSoulNode** → 输出灵魂注入 + 情感档案
2. **ConceptPitchPro** (或其他主节点) → 接收灵魂注入, 生成世界顶级导演级 prompt
3. **EditingPro** / **ArtDirectionPro** → 接收灵魂, 生成节奏 / 视觉
4. **QualityAssurancePro** → 质检
