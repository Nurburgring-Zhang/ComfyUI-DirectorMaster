# Phase 17.7 - 8 大世界顶级导演灵感时刻真实数据库

> **目的**: 让 AI 导演节点的输出不再"模板化"——通过真实电影中的具体灵感时刻,注入到灵魂节点,让输出像"活着的导演"在思考,而不是"规则集"在套用

> **AI-A 设计者**: Mavis (主 agent)
> **AI-B 审查者**: Verifier (自我审查)

---

## 1. 数据库设计原则

每条灵感时刻包含 8 个字段:
1. **导演**: 8 大世界顶级导演
2. **作品**: 真实电影/剧集
3. **场景描述**: 具体到分钟/秒的镜头
4. **情感核心**: 主导情感(用 60 情感矩阵 key)
5. **镜头技术**: 真实使用的镜头/运镜
6. **技术原因**: 为什么这么做
7. **灵魂维度激活**: D1-D10 哪些维度被激活
8. **可复用的 prompt 片段**: 节点可直接拼接

### 3.2 匹配算法 (草案)

```python
INSPIRATION_DB = [...]  # 上面的 32 条

def match_inspirations(fused_emotion, director, count=3):
    # 按情感类别 + 导演匹配
    primary = fused_emotion.get("name", "")
    matches = []
    for im in INSPIRATION_DB:
        if im["导演"] in director or director in im["导演"]:
            if primary.lower() in im["情感核心"].lower() or any(k in im["情感核心"].lower() for k in ["loneliness", "fear", "warm_regret", "lucid_despair", "tension"]):
                matches.append(im)
```

```python
# director_soul.py 末尾新增
def get_inspiration_moments(fused_emotion, director, count=3):
    """根据灵魂融合结果和导演,匹配真实灵感时刻"""
    matches = []
    primary = (fused_emotion.get("name", "") or "").lower()
    for im in INSPIRATION_DB:

                "loneliness", "fear", "warm_regret", "tension", "lucid_despair",
```
